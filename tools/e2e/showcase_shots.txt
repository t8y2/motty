# The three session captures behind the landing page's scroll-pinned showcase
# (website/public/showcase-base-dark.webp, showcase-light.webp and
# showcase-files.webp): the same session dark, light, and with the assistant
# closed. The light shot is the theme step; the closed shot is the files step.
# The module captures (hosts, forwards, colours) are in showcase_modules.txt.
# The first reveal only masks one capture over another, so the dark and light
# shots must be the same size with the same session and panel geometry.
#
#   (cd tools/e2esshd && go build -o /tmp/e2esshd .) && /tmp/e2esshd 2222 &
#   export SFTP_ROOT=<the "sftp root" path e2esshd prints>
#   python3 tools/e2e/hero_fixture.py "$SFTP_ROOT"    # the deploy tree, pinned dates
#   home=$(mktemp -d)
#   mkdir -p "$home/motty-data"
#   go run ./tools/e2e/heroseed "$home/motty-data/ai.db" "$SFTP_ROOT/logs/app.log"
#   go build -tags vivahead -o /tmp/motty-head ./cmd/motty
#   # substitute $SFTP_ROOT below, then run:
#   python3 tools/headless_drive.py "$home" /tmp/showcase.txt
#
# The driver owns MOTTY_DATA_DIR: it points it at <home>/motty-data, so the
# seeded database belongs there; an environment variable is overridden.
#
# The shot is 1560x975 points (2x = 3120x1950). The width is not decoration: the
# fixture's log lines run to 80 characters, and the assistant panel narrows the
# terminal enough that a 1400-point window wraps them, which reads as a broken
# log. 1560 keeps every line on one row.
#
# The terminal is clicked before each shot so the block caret is in the same
# blink phase; without it the caret shows up in the diff between the light and
# closed captures and flickers during the panel reveal. The click does not move
# the shell cursor.
#
# The host is saved as staging-web instead of connected ad hoc, because the tab
# title is the host's label. The files panel is opened with its toolbar button
# and the assistant with its window-bar button; the saved conversation is picked
# from 对话历史 by geometry. The assistant's target picker is driven by its IDs.
# `layout` reports the terminal/assistant divider as a crossing: it is the hit
# area that resizes the panels, not text over text.
#
# Convert with cwebp -q 88 -m 6, then copy the three files to
# website/public/showcase-base-dark.webp, showcase-light.webp and
# showcase-files.webp.
