## 新功能

- 终端里显示紧凑的传输进度卡片。
- AI 设置的服务商模型列表支持搜索过滤。
- 主机列表在主机增删或移动时带滑动动画，自动隐藏的侧边栏展开收起带弹性动效。
- 终端里选中文字后，右键一次即可粘贴。

## 修复

- 服务器拒绝刷新请求时，SFTP 上传不再中断。
- 分离的传输状态变化后，传输中心会及时重绘。
- SFTP 路径输入框里的长路径和光标保持在可见范围内。
- RDP 连接握手补发 Font List，兼容更多服务器。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
