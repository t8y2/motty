## New features

- A new version is announced with a toast and a button in the window bar instead of a dialog that interrupts what you are doing.
- On a slow link the text you type appears at once, without waiting a round trip.
- Closing a session that still has a host open asks first.
- A shell opened in a split pane starts in the directory of the pane it was split from.
- Double clicking a split pane's bar renames it, and the command palette can rename it too.
- The saved password can be filled in at a `sudo` prompt.
- Double click selects by word and triple click selects the whole line, and dragging on keeps selecting by word or by line.
- The settings can adjust terminal line spacing and cursor thickness.
- The AI panel shows request activity, duration and token usage.
- Holding a key in a remote desktop repeats it, so RDP no longer types it once.

## Improvements

- Each window keeps its own tabs, split panes, place and size. Starting the app reopens the windows the last run left open, and a new window starts empty instead of copying the last saved window's tabs.
- The update notice is a green ring with a solid arrow in the window bar.
- Command completion builds its trees only when a command is used, so the app holds about 10 MB less.
- The app icon is kept at 512 pixels, about 3 MB less.

## Fixes

- The blank after an icon is no longer folded into the same run, so Nerd Font icons are not clipped on Windows and Linux and a light line no longer appears beside powerline arrows.
- `motty mcp-serve` ends with its client, so the Windows installer no longer fails while `motty.exe` is held open.
- A reconnected shell is handed a terminal that no program still owns, so pointer moves stop being typed into it.
- Dragging a selection past the window edge keeps scrolling at the rate the edge asked for instead of half of it.
- SFTP saves remote text in place when the directory is read-only but the file is writable.
- Mouse reporting, the alternate screen and the kitty keyboard flags a killed program leaves behind are reclaimed at the prompt.
- The main window stays visible after an auto-update restart on Windows.
- `Shift+Insert` pastes and `Ctrl+Insert` copies in the terminal.
- Modified Enter chords are encoded consistently.
- Attaching a long pasted text to the AI panel is limited to 4 MiB.
