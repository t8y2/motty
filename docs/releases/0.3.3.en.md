## New

- A Traditional Chinese interface, chosen in Settings.
- Settings can choose the terminals and hosts that open when Motty starts; one that is already open is brought forward instead of opened twice.
- The terminal cursor can be a block, a bar or an underline.
- Shift-click extends the selection.
- Dragging a split pane's bar to the tab strip turns it into a tab.
- Changing SFTP permissions offers read, write and execute boxes for owner, group and others.
- The file editor's tabs share one window, with previews for images and text.
- Remote process details can be copied, and the process's environment read.

## Improvements

- The terminal side rail hides when it has no content.
- The font picker's focus follows the highlighted row.
- Picking from a list with a trackpad scrolls precisely.
- The new-tab button sits on the tabs' centre line.
- Tabs can be clicked from the window's top edge.

## Fixes

- When the clipboard holds only a picture, a paste sends an empty paste, which programs such as OpenCode need to read the picture themselves.
- When the system refuses to run the new version, the update dialog explains why (a missing notarization ticket or an unreachable Apple service) and suggests checking the network or downloading the DMG, instead of showing the system's raw output.

## Install

| Platform | Packages |
| --- | --- |
| macOS (arm64, amd64) | `.dmg`, `.zip` |
| Windows (amd64, arm64) | installer, portable zip (data in `motty-data` beside the program) |
| Linux (amd64, arm64) | `.deb`, `.tar.gz` |
