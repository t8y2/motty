## 新功能

- 终端背景图的可见度可以在 0–100% 之间自由调节。

## 改进

- 启动时本地终端在第一帧就能用输入法输入。

## 修复

- Windows 10 的 PowerShell 里输入空格或删除内容后，不再留下黑色残块。
- 双击选词时，路径和地址不再被截断。
- 标签栏滚动条平时保持细线，鼠标移上去才加粗。
- 文件传输标签里的属性对话框可以正常关闭。
- 转发 ssh-agent 时，每个转发通道各自重新连接 agent。
- SFTP 文件列表里的修改时间显示完整。
- 滚轮翻页按窗格所在屏幕的尺寸计算行数。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
