## New features

- Workspaces gain main + right, main + bottom and tabbed layouts; a tabbed workspace shows one terminal at a time behind a tab strip.
- Drag a card onto the edge of another in the layout menu to draw your own split. In a running workspace, drag a terminal's bar onto another terminal's edge to dock it there, or onto its middle to swap the two.
- Middle-click closes a tab.
- Snippets can be ordered by hand and hold multi-line commands.
- Several hosts can share one saved password, managed under Settings > Security; changing it once updates every host that uses it.
- Snippets can sync through Gitee.
- Settings can configure the separators used when double-clicking to select a word in the terminal.
- The new-tab picker collapses local shells into one group.

## Improvements

- The workspace header's buttons share one 13pt label size, and the bar is shorter.
- The assistant's settings stay in step across open windows.
- The terminal's columns and rows follow the font's own metrics, so Consolas on Windows no longer looks loose.
- Hover and focus looks follow the framework's shared states.

## Fixes

- Commands sent to Telnet and serial device consoles go out exactly as typed, with no shell wrapper.
- Remote desktop receives files copied on the server.
- Local terminals stay responsive while the window is resized live.
- Opening the terminal find bar no longer hides the side rail.
- The first hide into the status area is explained.
- Workspaces behave consistently with remote desktop in native fullscreen.
