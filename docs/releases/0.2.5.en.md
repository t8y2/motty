## New

- The SSH host form gains a Test Connection button that dials the host as typed without saving it and says how far it got: connected, reachable but not verified, or why it failed.
- An SSH host can set a command after login; it is typed into each new shell once ready and stays out of history and broadcast.
- The autofill rules page adds sudo and su presets that open the rule dialog filled in; a rule still starts off and asks before its first send.
- Import reads a Netcatty CSV export: SSH and Telnet rows become hosts. Passwords stored in the clear are not imported; delete the file afterwards.
- Keyword highlighting imports rules from a text file and reports how many were added and skipped.
- Inline command suggestions fall back to commands typed on your other hosts when this host's own history has no match.
- The import chooser links to an Import guide that says where each client exports its file from.

## Improvements

- Deleting an autofill or highlight rule asks first and says when the saved text goes with it.
- The macOS disk image opens as a drag-to-Applications window with an arrow background.

## Fixes

- Predicted echo is muted only; it is no longer underlined on a slow link.
- RDP asks for a desktop the size of the pane at the display's scale and draws it unscaled, so text stays sharp; it follows pane resizes.
- A saved RSA host key keeps ssh-rsa offered, so a device that can sign only with ssh-rsa reconnects instead of failing with no common host key algorithm.
- A WebDAV upload into a folder the server will not create names that folder instead of only reporting 409.
