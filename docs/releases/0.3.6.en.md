## New features

- A notes library: write Markdown notes in the terminal sidebar, with new notes, folders, import and export, and search, synced with your settings.
- The connect picker can select several hosts and connect them as one twelve-pane workspace.
- Tabs are numbered in order, and holding the number-key modifier with 1–9 opens that tab.
- The file transfer window has a directory tree that reads a directory only when it is expanded, plus synchronized browsing once both sides point at matching directories.
- Snippets can belong to a group: the snippets page and the terminal's snippet picker are sectioned by group and search matches the group name, and leading and trailing spaces in a command are kept.
- Hosts at one address can be saved separately when their names differ, so a bastion with several targets no longer fits only once.
- The host list has bulk selection, and can display hosts ordered by name or by IP.
- Clicking on the command line moves the shell cursor there; programs that own the mouse and full-screen programs are left alone, and a setting turns it off.
- MCP adds `terminal_start`/`terminal_poll`/`terminal_stop`: a long command runs in the visible terminal and returns a job id at once, new output is read by offset, and retained output can be paged.
- MCP can list the saved hosts an agent is authorized to reach.
- A provider whose model listing lives at a different address from its completions can name that address separately.
- The local shell list reads `/etc/shells` and searches the standard install prefixes, so csh, tcsh, ksh, dash and a Homebrew shell are all offered; on Windows a Cygwin installed to a custom directory is found too.
- Settings shows the interface font's name beside its choose button.

## Improvements

- The default split shortcuts are now Command+D / Shift+Command+D on macOS and Control+Shift+D / Control+Shift+E elsewhere, no longer taking the system's hide and window chords; a table still holding the old default is migrated once, and a chord you chose or a snippet already sends keeps its owner.
- Completion fills the shared prefix of several matches, and history matches are ordered by most recent use.
- Filtering the host list by group keeps the child hierarchy, so you can drill down one level at a time.
- A pinned group shows its star on its filter chip.
- The host import button has a clear accessible name for both import and export.

## Fixes

- A drag selection in the terminal survives a pointer exit that carries no coordinates.
- A settled transfer no longer holds its paths, so the next operation on the same path is not told to wait for it to settle.
- Editing a host no longer closes the connect picker.
- The target trigger in the AI drawer stays below an open menu.
