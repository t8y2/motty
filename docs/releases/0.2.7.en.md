## New

- A desktop session with Share clipboard enabled receives a local copy as soon as it happens, without the pointer moving first.
- On Windows, a remote desktop that holds the keyboard also takes the Windows key, Alt+Tab, Ctrl+Esc and their chords, and gives them back when the keyboard does.
- A remote desktop shows its pointer shape as the system cursor.
- A host can reach its connection through a local command (`%h`, `%p`, `%r` for host, port and user); a ProxyCommand imported from the SSH config runs only after it is confirmed.
- Jump routes can be started and stopped by hand, the list shows whether each is running, and new connections follow that state.
- Settings > Connection can give local terminals the system proxy (`HTTP_PROXY` and friends); it is off by default, applies to new and reconnected terminals, and skips WSL.

## Improvements

- The terminal gutter for line numbers and times uses the fixed-pitch face and the scheme's bright cyan on a faint panel, so the time column lines up.
- Settings > Terminal gains Bold text: bright + bold, bright, bold or unchanged, bright by default as Windows Terminal draws it.

## Fixes

- Terminal cells fall on whole device pixels, so the thin white line beside powerline glyphs on Windows is gone.
- Backslashes in a Windows IdentityFile path are no longer read as escapes.
- The update dialog's release notes scroll with the scrollbar.
- In kitty keyboard mode, Shift+Enter is sent as its own key, so programs such as Codex can tell a newline from submit.
- The files panel's toolbar button closes the panel.
- Windows reports a data directory below a file at launch instead of failing later.
