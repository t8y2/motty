## New

- An RDP desktop accepts files and folders copied here: press Ctrl+V in the remote desktop. Nested folders and non-ASCII names work, and a selection over the limits is refused outright instead of cut short.
- The file window has a code editor: line numbers, the current line, bracket matching, auto-indent and paired brackets; find and replace cover case, whole words and regular expressions, F3 steps through matches and Ctrl+G jumps to a line.
- The keychain can paste a private key or generate a new Ed25519 one, and copy the public key; pasted and generated keys are sealed in the vault and follow it through sync and backup.
- A terminal toolbar button sends a quick command after a search.
- Transfer progress shows on the application icon.

## Improvements

- The compare-and-save view and the code editor share one fixed-pitch character grid and tab width, and its right pane edits with the editor's keys.
- A Japanese README.

## Fixes

- The assistant's terminal_exec works in a PowerShell session; shells it has no wrapper for, such as cmd, fish and nushell, now say so instead of waiting for a timeout.
- A GB18030 session file without a BOM is read as Chinese.
- Exporting the connection log no longer writes a notice into the terminal screen, so typing no longer looks stuck.
- A data directory reached through a link, such as Scoop's `current`, no longer stops Motty from starting.
- The new-tab and quick-command lists draw a slim scrollbar that can be dragged and clicked, instead of a thumb over the rows.
- A tab shows the host name by default again, reverting the default changed in 0.3.1; Settings can turn on following the terminal's title.
