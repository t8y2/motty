## 新功能

- 双击标签页的动作可以设为关闭标签页。
- 设置里可以选择通知出现的位置。
- 主机可以随机分配颜色。
- 传输卡片紧凑显示时，逐个列出各个传输任务。
- mcp-serve 新增主机资源和最近活动工具。

## 改进

- 删除远程文件夹时，SFTP 并行发送请求，速度更快。
- 终端内的程序接管鼠标时，显示箭头指针。

## 修复

- 终端较宽时保留完整的回滚行数配置。
- 按住分隔条拖动经过笔记面板时，不再丢失拖动。
- 命令片段页为空、树折叠或窄屏未开抽屉时，右键不再导致崩溃。
- SFTP 回到根目录时，不再重复刷新，符号链接目录不再跳动。
- 密码和验证码对话框外点击不再取消连接。
- RDP 在 macOS 上用 Command+C、Command+V 复制粘贴，多行文本和图片可以原样粘贴。
- RDP 仅在服务器接受时才发送扩展客户端数据。
- RDP 跟随服务器重定向时，在 MS-RDSTLS 里提交重定向 cookie。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
