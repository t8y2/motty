## 新功能

- 笔记可以链接到 Markdown 文件：笔记内容就是源文件，在其他软件里修改会自动同步，在 Motty 里编辑会写回文件；文件和笔记同时被修改时，可以选择载入磁盘版本、保留我的并覆盖，或另存为新笔记。
- 笔记可以链接整个文件夹：文件夹里的 Markdown 文件和子文件夹会成为笔记和笔记文件夹，增删改名都会跟随；删除笔记不会删除磁盘上的文件。
- 重连后终端会回到之前所在的远程目录。
- SFTP 文件树支持键盘导航。

## 改进

- 终端滚动更流畅，Windows 上只重绘新进入视口的行。
- 本地 Shell 探测增加用户级 bin 目录，如 `~/.cargo/bin`、`~/.local/bin`。

## 修复

- 远程桌面窗口缩放后不再出现画面撕裂或黑屏。
- 通过跳板机的 SFTP 上传不再卡住，取消传输也不会断开整个连接。
- 修复旧版本遗留的工作区布局记录导致笔记无法选择、无法删除的问题。
- 社区徽标文字居中。

## 安装

| 平台 | 包 |
| --- | --- |

| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
