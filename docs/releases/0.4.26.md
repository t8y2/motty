## 新功能

- 同步支持用 GitHub CLI 登录来使用 Gist 同步。
- 会话管理器新增“全部展开”和“全部折叠”。
- 快捷键页新增“全部清除”按钮。
- 快捷命令可以单独设置为按行逐条发送多行命令。
- VNC、RDP 主机新增画质与带宽选项，VNC 会话运行中也可以调整画质。
- 窗口启动时恢复上次的最大化状态。

## 改进

- 主机列表中的系统图标按 A-Z 排序。
- Windows SSH 主机上的 PowerShell 终端也能跟随当前文件夹。

## 修复

- 密钥认证被服务器部分接受后继续后续认证，不再中断。
- 已保存主机密钥后，其他类型的主机密钥仍会继续提供。
- 命令运行期间不再触发空闲保活。
- 远程桌面的跳板机目标能正确恢复和选择。
- 切换设置标签页后保留各页状态。
- 服务器拒绝修改权限时，SFTP 上传仍能完成。
- 兼容 1.2.0 之前版本服务器的 trzsz 通告。
- 远程桌面剪贴板支持 UTF-8 文本的收发。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
