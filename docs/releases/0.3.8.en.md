## New features

- A note can be linked to a Markdown file: the file is the note, edits made in other apps show up on their own, and edits in Motty are written back. If both change at once, choose between loading the disk version, keeping yours and overwriting, or saving yours as a new note.
- A whole folder of Markdown files can be linked as notes: files and subfolders become notes and note folders, and additions, removals and renames are followed. Deleting a note never deletes the file on disk.
- After a reconnect the terminal returns to the remote directory it was in.
- The SFTP file tree supports keyboard navigation.

## Improvements

- Terminal scrolling is smoother; on Windows only the rows entering the viewport are redrawn.
- Local shell detection also looks in user bin directories such as `~/.cargo/bin` and `~/.local/bin`.

## Fixes

- A remote desktop window no longer tears or goes black after being resized.
- SFTP uploads through a jump host no longer hang, and cancelling a transfer no longer drops the whole connection.
- Fixed notes that could not be selected or deleted because of a leftover workspace layout record from an older version.
- The community badge text is centered.
