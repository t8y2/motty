## 新功能

- 文件面板可以把终端切换到当前目录。
- AI 设置可以统一决定 MCP 代理能使用哪些主机：不允许、跟随主机设定或全部允许。

## 改进

- 笔记库与笔记侧栏只绘制可见行，笔记很多时滚动更流畅。
- 新标签页选择器会记住本地终端 shell 列表的展开状态。

## 修复

- 修复远程桌面窗口隐藏后心跳把无输出当作断线、导致连接被断开的问题。
- 修复远程桌面的 32 位光标不按透明度绘制的问题。
- 修复命令补全中过长的路径把候选名称截断、难以区分的问题。
- 修复仅允许交互式会话的主机在保活探测时被网关断开的问题。
- 修复第一次出现 SSH 提示符时不能补全路径的问题。
- 修复 macOS 菜单「编辑」中的复制不生效的问题。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
