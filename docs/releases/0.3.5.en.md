## New features

- Hosts can be dragged into your own order in the host list; the previous order stays the default.
- A saved port forward or jump route can be edited instead of deleted and rebuilt.
- Port forwards resume after an automatic reconnect with the session that owns them.
- When remote files need higher privilege, switch on the `sudo` toggle and confirm the password: the file browser, its transfers and open documents move to a privileged SFTP server. The terminal is never elevated, and the password is kept only for the connection.
- MCP lets an external agent transfer files inside a scope you name, and returns execution results in a structured form.
- On Linux a signed `.deb` is installed through Polkit and dpkg.

## Improvements

- Nested host groups are browsed one level at a time: the filter chips show the level in view, a chip with subgroups carries a chevron to open them, and the group field in the New Host dialog works the same way.
- Option+Left and Option+Right move by word, as they do in macOS Terminal.
- Large bursts of terminal output are no longer held back by a fixed cap, and a key press is not queued behind a backlog.
- Typed-ahead text (not yet confirmed by the server) is drawn in the terminal's own color and appears or withdraws by measured latency.

## Fixes

- The files panel's More menu and its backdrop are painted on the page canvas, so the Settings button is no longer covered and the menu closes again.
- The wheel no longer scrolls the host list underneath an open filter chip menu.
- A folder imported from MobaXterm and the other session formats no longer appears twice.
- A block cursor stays visible while an echo is pending.
- A local session can paste an image when the clipboard holds no text.
- On Windows the `motty.exe` can be replaced while `motty mcp-serve` runs, so the installer no longer fails.
- Member names inside a Chinese Xshell archive are decoded instead of garbled.

## Install

| Platform | Packages |
| --- | --- |
| macOS (arm64, amd64) | `.dmg`, `.zip` |
| Windows (amd64, arm64) | installer, portable `.zip` (data in `motty-data` beside the program) |
| Linux (amd64, arm64) | `.deb`, `.tar.gz` |
