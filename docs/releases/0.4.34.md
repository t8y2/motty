## 新功能

- AI 可以按服务商单独设置出站代理。
- 片段页新增目录树和行内编辑。
- 工作台桌面栏全屏时可以拖到任意位置或边缘。
- SSH 主机可以选择 Backspace 键和擦除字节。
- 串口和 Telnet 主机可以用 Ctrl+H 作为 Backspace。
- AI 提问右对齐，粘贴到输入框的文件会作为附件。

## 改进

- 标签栏标签过多时出现滚动箭头。
- 小文件夹上传同时发送更多文件，速度更快。
- 同步面板沿用文件面板的显示选择。
- 无法读取系统代理时，更新检查可以直接重试。
- 导出的私钥在 Windows 上仅限本人访问。
- Podman 在所有 Unix 发行版上都会尝试。

## 修复

- 关闭 SSH 隐式 TCP 保活，避免误断开。
- 登录后在仅有提示符的 shell 里能正确输入命令。
- RDP 远程指针的反色效果显示正确。
- MCP HTTP 端点默认端口保持稳定。
- 锁定界面恢复原生标题栏手势。
- 远程日志的长路径可以继续编辑。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
