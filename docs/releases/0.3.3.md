## 新功能

- 新增繁体中文界面，可在设置里切换。
- 设置可以指定启动时自动打开的终端和主机；已经打开时切换过去，而不是重复打开。
- 终端光标样式可以选择块状、竖线或下划线。
- 按住 Shift 点击可以扩展选择范围。
- 把分屏的标题栏拖到标签栏，就把它变成一个标签页。
- SFTP 修改权限时提供所有者、属组、其他的读取/写入/执行勾选框。
- 文件编辑器的多个页签共用一个窗口，并支持图片和文本预览。
- 远程进程详情可以复制，并能读取该进程的环境变量。

## 改进

- 终端侧边工具栏没有内容时自动隐藏。
- 字体选择器的焦点跟随高亮的行。
- 触控板滚动选择列表更精确。
- 新建标签按钮与标签中心线对齐。
- 窗口顶边也能点到标签页。

## 修复

- 剪贴板里只有图片时，粘贴会发送一次空粘贴，OpenCode 这类自己读取图片的程序能正常接受。
- 系统拒绝运行新版本时，更新对话框会说明原因（缺少公证票据或连不上 Apple），并提示检查网络或直接下载 DMG，而不是只显示系统的原始输出。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
