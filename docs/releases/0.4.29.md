## 新功能

- SFTP 文件列表可以新建文件，也可以通过右键菜单跳转到符号链接的目标。
- SFTP 文件浏览器支持拖拽移动文件。
- 全屏远程桌面时，顶部工具栏可以固定。
- MCP 设置里可以选择允许代理传输文件的本地文件夹。

## 改进

- 登录后的多行命令逐行执行。
- 复制标签页时保留布局，最大化时也能调整标签顺序。
- Windows 安装程序和程序文件现在带代码签名。

## 修复

- 网络变化后端口转发可以自动恢复。
- 输入较快时，补全可以在提示符之后立刻调出历史命令。
- MCP 服务启动之后开放给代理的主机也会列出。
- 文件编辑器里的粘贴不再进入终端。
- 切换抽屉后笔记预览会重新排版。
- 远端文件夹被删除后，SFTP 面板仍留在服务器上。
- 传输期间阻止系统休眠不再卡住界面。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
