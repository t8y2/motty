## New

- File transfers open as tabs or separate windows, with either side on the left; a file info panel shows path, type, size, modified time, permissions, owner, group and link target.
- File transfer can use a custom program: it opens local files, and a remote file is downloaded first and synced back when saved.
- The file filter can search subfolders, showing matches, entries read and folders it could not read.
- Session logs record the whole lifecycle (start, host key, authentication, end and recovery), can filter by outcome, and can reopen a session, locate its host or copy the record; several records can be selected.
- Tabs can sit at the top or as a vertical bar on the left; the vertical bar can auto-hide and group connections by server.
- Settings > General chooses the interface font used by windows, menus and settings pages.
- A remote desktop can show the picture only, hiding its top bar and status bar.
- The resource monitor reads macOS hosts and this computer's local terminal.
- Backup and sync gains Test connection and Restore from remote; a safety copy is kept before restoring.
- A jump route can relay through the jump host's shell, for bastions that only offer a shell.

## Improvements

- Interface text can be small, regular or large; windows and settings pages scale together.
- The terminal toolbar is shared across the workspace and can sit on the left or right, following the active split.
- SFTP uploads use pipelined writes with a sliding window, so they finish sooner.
- The monitor caches dashboard charts and builds only the rows in view; macOS no longer shows an empty per-core section.
- Changing the terminal font previews it and asks before saving.

## Fixes

- The built-in completion catalog's update is repaired and its content audited.
- Deleting a folder over SFTP removes everything inside it after a confirmation.
