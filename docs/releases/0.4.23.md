## 新功能

- 快捷命令从终端下方的横条改为终端右侧的侧栏，命令多时可以上下滚动。
- 从远程桌面复制的文件在下载时显示进度，可以取消，进度也计入程序坞图标。
- 端口转发的每条记录直接提供编辑、启动和删除按钮。
- 本地终端里打印的路径可以在右键菜单中在文件夹里显示。
- 主机页能识别 Alibaba Cloud Linux 并显示对应的系统图标。

## 改进

- 关闭停在提示符、没有运行程序的终端标签时不再弹出确认。
- 资源监控显示当前登录的 SSH 用户。
- 终端中的 Ctrl+W 交给 shell 删除前一个单词，不再关闭标签页。
- 多台设备同步设置时一并同步工具栏布局、顺序和停靠位置。
- 终端文本选择可以跨软换行继续高亮。
- 发送快捷命令后焦点回到终端，可以接着输入。
- 远程桌面断开后在画面中央显示断开原因和重连按钮。

## 修复

- 同一堡垒机账号下的不同保存主机各自建立连接，不再落到另一台主机的资产上。
- 远程桌面的声音不再阻塞画面更新，其他会话不会跟着卡住。
- 远程桌面断开后系统光标恢复为普通指针。
- 传输中心的批量替换和续传确认改为标准对话框，不再占满整个列表。
- 远程工具窗口里的滚轮只滚动当前面板，不再落到下层控件。
- Windows 的 Win32 输入模式下可以正常接受命令补全候选。
- MCP 客户端在服务端取消调用后仍能收到结果，会话不会失效。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
