## 新功能

- 关于页和更新弹窗可以选择更新源：官方镜像或 CNB。选择会保存；CNB 是中国大陆的镜像，读不到时自动回到官方源。
- 可以用 ⌘,（Windows/Linux 为 Ctrl+,）或菜单直接打开设置。
- 崩溃提示里可以直接打开崩溃报告。

## 改进

- 上传文件夹时多个文件并行上传，文件多、体积小的目录明显更快。
- 远程会话中的程序现在能识别真彩色终端。
- 本地代理设置里 Docker 的说明更清楚。

## 修复

- 更新弹窗重新显示发布说明。
- 检查更新和下载跟随系统代理，配置了代理的网络上不再因为直连超时而失败。
- 修复工具窗口滚动导致崩溃、表格空白的问题。
- 修复对话框里滚动会继续滚动后面的页面、甚至导致崩溃的问题。
- 修复命令标签的菜单里无法编辑或删除该标签的问题。
- 修复部分远程桌面（RDP）连接中光标显示异常的问题。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
