## 新功能

- 快捷命令按分组显示，点击组标题可以折叠，折叠状态会保存。

## 改进

- 快捷命令可以重新停靠在终端下方横条，右侧侧栏仍可从同一选择器切换。

## 修复

- 更新弹窗的更新源下拉不再与底部按钮重叠，英文界面或窄窗口下也完整显示。
- 上传、下载或复制包含符号链接的文件夹不再中断，链接会按链接重建（例如 macOS 的 .app 应用包）。
- 同时打开文件面板时，连接不再抢在终端 shell 之前建立，登录消息（MOTD）正常显示。
- 使用远程桌面时，点击标签页、工具栏或菜单后，Alt+Tab 仍会切到远程桌面。
- 多行粘贴确认框打开时焦点在“粘贴”按钮上，Enter 直接粘贴，Esc 取消。
- Windows 下从文件管理器切回后，文件面板的目录树能显示新建的文件夹。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
