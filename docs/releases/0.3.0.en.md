## New

- Workspaces: save a set of terminals from several hosts and open them together, or keep them as templates; the terminals are laid out on a grid.
- Remote process management is complete: list a host's processes with PID, parent, user, state, CPU and memory, in the panel or in its own window.
- AI settings can measure a model endpoint, or all of them at once with a concurrency and timeout you set, and list only models that can chat or reason.
- A shortcut can be almost any key or combination: a single key, punctuation, space, navigation keys or F1–F12, with any modifiers.
- Session logs can be sorted and filtered, and remember the last view.
- The new-tab host picker can sort by last login and shows times such as "just now" and "N seconds ago".
- Background output alerts tint the tab title for output you have not seen: blue while it streams, green when it ends or goes quiet, and yellow when a command fails.
- Import can save readable plaintext SSH passwords from the export, after showing how many and asking, and never overwrites an existing password; an ambiguous MobaXterm file asks for UTF-8 or GB18030.

## Breaking changes

- A shortcut can now take almost any key, and a bound key reaches the shortcut before the terminal. The defaults are unchanged; only bindings you add take keys away from programs.
- On macOS, a Command chord that no Motty action uses is sent to the program once it enables the kitty keyboard protocol, instead of being dropped.

## Improvements

- The terminal writes characters in runs of one width and resolves a cell style once per run, so scrolling and heavy output are faster.

## Fixes

- A window that kept failing to save after another window saved now reloads the shared records and saves.
- A new shell after a reconnect no longer inherits the previous program's kitty keyboard modes.
- The host tag dropdown is no longer clipped by the form's edges.
- The jump and target host dropdowns scroll with the wheel.
