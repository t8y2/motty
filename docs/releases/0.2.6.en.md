## New

- Saving over SFTP can compare the server's current text with the local edits in two panes; a direct save asks first, and a file changed on the server is not overwritten silently.
- The file panel's more menu can hand the current folder to VS Code or Zed; choose the default editor under Settings > Files.
- A running session can be disconnected or reconnected, each after a confirmation; a disconnect keeps the tab and its screen, and the tab can connect again.

## Improvements

- Resizing the window reflows the terminal's main screen and scrollback instead of truncating them.
- Quick commands hold up to 512 entries, up from 48.
- The resource monitor's side panel builds only the rows in view, so a host with many mounts stays smooth.

## Fixes

- While an input method composes, placeholder text at the cursor no longer shows through the preedit.
- The assistant starts every line of a multi-line command at column 0.

## Install

| Platform | Packages |

| Windows (amd64, arm64) | installer, portable zip (data in `motty-data` beside the program) |
| Linux (amd64, arm64) | `.deb`, `.tar.gz` |
