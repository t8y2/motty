## New

- The tab menu moves a tab to a new window, and a tab can be dragged out of every window; on macOS a picture of the tab follows the pointer while it is dragged.
- A remote host can reuse the local HTTP proxy: an SSH tunnel exposes the local HTTP proxy to the server, with the setup and undo commands copied in one step and a Docker section.
- Host groups expand or collapse at once, and the host list keeps its filter.
- The host list and the new-tab picker match every keyword, not only the whole phrase.
- Command completions list up to five history matches.
- Control+1–9 jumps to that tab on Windows and Linux.
- A completed download can be revealed in the file manager.
- The Homebrew cask and Scoop manifest are published: `brew install --cask t8y2/tap/motty` or `scoop install t8y2/motty`, which then update with the package manager.
- A tab follows the title its terminal reports by default, and shows the host name only when the program reports none; the setting can be turned off.

## Improvements

- The sidebar remembers the width it was last resized to.
- The session name is centred over the workspace and kept clear of the buttons on either side.
- A narrowing window keeps a single drawer instead of stacking them.
- The light theme is softer: panels are no longer pure white and the ink is slightly softened.
- Dashboard and toolbar buttons size to their labels.
- The terminal's common path for checking a character's width is faster.
- The host list bar uses the framework's scroll area.

## Fixes

- The vertical tab list's scrollbar appears on hover and can be dragged.
- Hovering a tab shows its full title.
- A shell that starts slowly still gets the right terminal size.
- A system probe that times out no longer closes its session.
- The update check no longer reports an unverified package as missing.
- Group context menus open from the filter chips.

## Install

| Platform | Packages |
| --- | --- |
| macOS (arm64, amd64) | `.dmg`, `.zip` |
| Windows (amd64, arm64) | installer, portable zip (data in `motty-data` beside the program) |
| Linux (amd64, arm64) | `.deb`, `.tar.gz` |
