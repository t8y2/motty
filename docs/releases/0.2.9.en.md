## New

- Hosts support nested groups: rename, add a child group, move a whole group, pin and reorder them; deleting a group can move its hosts elsewhere.
- Host and tab menus can copy the connection name, or its address and port.
- Toolbar icons can dock at the top, in upper and lower groups on either side, or in left and right groups at the bottom; they can be hidden, dragged into order, and the default layout restored.
- The side and bottom toolbars can be sized small, medium or large.
- A shortcut binding can be deleted, then reads "—"; Restore defaults moved to the page header.
- An RDP desktop can go fullscreen and shows the network latency the server reports; Settings > Terminal's Show latency also covers SSH terminals.
- A host seen as a NAS, router or Linux distribution shows that brand's mark.

## Improvements

- Connection colours stay on tabs and host markers; terminal, file and monitor headers use neutral backgrounds.
- The About page's links use each brand's mark.
- Closing a tab returns its memory to the OS.
- Terminal control-string parsing and scrolling are faster.

## Fixes

- An unconfirmed input-method preedit is no longer saved by the snippet editor.
- Escape still reaches the terminal while the file panel is open.
- RDP falls back to raw NTLM tokens when the server rejects SPNEGO, so Windows sign-in no longer fails.
- CJK runs stay on their cells after backspace.
- Clicking outside a form no longer clears what was typed.
- The shortcut recorder's close button highlights only under the pointer.
