## 新功能

- 应用可以用主密码锁定。
- 可以在设置里开关系统托盘图标。
- 终端支持背景透明度（macOS）。
- RDP 主机可以设置远程分辨率，也能在桌面栏里临时切换。
- 所有文本框都有系统的编辑右键菜单。

## 改进

- 文件侧栏的最大宽度与监控面板一致。
- 更新重启提示只统计会被断开的会话。

## 修复

- 在 Nushell 里不再注入 bash/zsh 集成脚本。
- 切换标签页或后台连接时，SFTP 不再重新加载。
- 兼容 RFB 4.0 和 4.1 的 VNC 服务器。
- 高延迟断线不再被误判为探测被拒。
- 主机对话框里密钥丢失时可以直接恢复保险库。
- 返回主机页后列表滚动位置保持不变。
- 查找框的透明度滑块在窄行里可以收缩。
- 补全列表在 shell 预测旁正常展开。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
