## 新功能

- 本地 AI 助手支持 Qoder CLI。
- 本地 AI 助手支持 OpenCode CLI v2 会话。
- 命令补全会提示 docker compose 等 CLI 插件的子命令。
- 自动补全列表会带上其他主机用过的命令。
- macOS 窗口显示「文件」「编辑」「显示」菜单，菜单项随当前会话状态更新。

## 改进

- 主机编辑器的「高级」里可以只允许自动认证使用配置过的 SSH 密钥。

## 修复

- 修复重连倒计时被下方按钮遮挡或截断的问题。
- 修复 macOS 上查看远程桌面时本地输入法被触发、在画面里弹出候选窗并干扰被控端输入的问题，按键现在交给被控端自己的输入法。
- 修复 Linux 与 macOS 上 Ctrl+Shift+C 不能复制、反而向终端发送中断的问题。
- 修复经 Rosetta 运行的应用在远端监控里把内存用量显示为实际四分之一的问题。
- 修复 Linux 上切换焦点后输入法可能仍作用于此前的输入框的问题。
- 修复 SSH agent 中密钥很多时，配置的密钥可能不被使用、导致无法登录的问题。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |

| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
