## 新功能

- AI 服务商编辑表单可以显示已保存的密钥。
- 串口的线路字段旁提供常用波特率。
- 鼠标移到终端上时显示文本指针。
- 全屏时的工具栏记住边缘位置，并标出隐藏处。
- AI 请求运行期间可以更改审批范围。

## 改进

- 设置页可以用键盘滚动，并显示滚动条。

## 修复

- RDP 复制的会话文件在粘贴前保留在服务器上。
- RDP 反色指针交给系统光标绘制。
- RDP 客户端跟随重定向时保持会话不断开。
- Windows 本地 shell 每次启动都重建用户环境。
- AI 助手面板上方的对话框可以用滚轮滚动。
- 终端回车后保留预测输入，直到回显到达。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
