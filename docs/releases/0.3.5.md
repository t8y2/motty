## 新功能

- 在主机列表里手动拖动排序，默认顺序照旧。
- 已保存的端口转发和跳板路由可以直接编辑，不用删掉重建。
- 断线自动重连后，随该会话启动的端口转发接着恢复。
- 远程文件需要更高权限时，打开 `sudo` 开关并确认密码，文件面板、传输和打开的文档一起切换到特权 SFTP；终端不会被提权，密码只留在本次连接。
- MCP 允许外部代理在指定目录内收发文件，并按结构返回执行结果。
- 在 Linux 上通过 Polkit 和 dpkg 安装签名后的 `.deb`。

## 改进

- 主机分组支持逐级浏览：筛选条的 chip 显示当前层级，带子分组的 chip 有箭头往下钻，新建主机时的分组选择也一样。
- 切到 macOS 的终端习惯：Option+左右箭头按词移动光标。
- 终端解析大段输出不再受固定上限拖住，刷屏时按键也不会排在积压后面。
- 候选文字（尚未被服务器确认的输入）用终端自身的颜色显示，按延迟自动出现或撤回。

## 修复

- 文件面板的更多菜单和它的遮罩画在页面画布上，设置按钮不再被挡住、菜单能正常关闭。
- 主机列表上的筛选 chip 打开菜单时，滚轮不再滚动底下的主机列表。
- 导入 MobaXterm 等会话时，同一文件夹不再出现两次。
- 块状光标在等待服务器回显期间不再消失。
- 剪贴板里只有图片时，本地会话可以把图片粘贴进去。
- Windows 上 `motty mcp-serve` 运行期间也能替换 `motty.exe`，安装不再失败。
- 中文 Xshell 归档里的成员名不再乱码。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
