## 新功能

- 主机目录可以用密码加密导出和导入。
- 密钥库中已保存的 SSH 密钥可以编辑、复制和显示。
- SFTP 可以对多选项批量修改权限，并可递归应用。
- 传输中心、冲突对话框和文件设置重新设计。
- 主机密钥、错误信息和详情文字可以选中并复制。

## 改进

- 代码片段的命令输入框旁说明了变量的写法。

## 修复

- 终端有选区时，右键复制选区（开启选中即复制时除外）。
- 深色主题的 ANSI 黑色与终端背景一致。
- 终端在 PS1 清行后正确记录提示符起始列。
- RDP 支持 GNOME 远程桌面的远程登录重定向。
- RDP 指针位图变化时，反色指针正确重绘。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
