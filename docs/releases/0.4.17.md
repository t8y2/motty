## 新功能

- 状态栏菜单可以直接打开已保存的主机和工作区，不用先显示窗口。
- 片段组可以重命名和删除，改名或删除后组内命令跟着更新。
- 设置 > 文件 里可以调整文档预览的大小上限，不再固定为 16 MB。

## 改进

- 删除文件后列表只移除删掉的行，保留当前位置、滚动和选中。

## 修复

- 保存的密钥密码短语不再被误判为错误，粘贴或生成的密钥也能直接连上。
- 远程终端里的程序拿到真实的字符像素尺寸，按字符排版图片的工具不再显示错位。
- 修复位置配置的快捷菜单弹在页面角落、选不中条目，以及预览浮层留在菜单后面的问题。
- 修复命令较长时片段列表的列错位。
- 修复监控面板的图标条和图表显示异常。
- SFTP 里符号链接按目标显示图标，断链仍保留链接标记。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
