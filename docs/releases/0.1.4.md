Motty 0.1.4：外部 agent 不开 Motty 也能通过 stdio 用上你对它开放的 SSH 主机；窗口栏多了一个 GitHub 按钮；主机设置的高级选项按用途重新分组；内联大图不再卡住终端，主机多的时候保存也更快。

## 新功能

- **不开窗口的 MCP 服务。** `motty mcp-serve` 是走 stdio 的 MCP 服务：客户端需要时自己启动它，不用端口也不用 token，客户端退出它就结束。它只用你在主机「高级」里开放给 agent 的主机，连接由它自己建立。
- **权限只有两档。** 默认「只读」可以列目录、读文件；「命令」档额外放行低风险命令。因为没人可以被询问，任何需要确认的操作一律拒绝；它不会自行信任主机密钥，密码取自已保存的密码。
- **调用记录。** 每次调用都会记进设置 > MCP（不含输出），保留 30 天；日志打不开时服务直接拒绝启动。
- **接入客户端。** 设置 > MCP 里有各家客户端的配置片段，复制即可；Motty 不必打开。
- **窗口栏的 GitHub 按钮。** 窗口栏右上角多了一个 GitHub 按钮，点开就是项目主页；原来的语言按钮去掉了，语言仍在设置里选。

## 改进

- 主机设置的高级选项分成「会话」和「AI agent」两组，名称和颜色排在同一行；「允许 MCP agent 使用此主机」改成带帮助提示的说明，不再是光秃秃的复选框；代理摘要变成和其他输入一致的有边框盒子，开关行的间距也调匀了。
- 内联图片（iTerm2、kitty、sixel）改到后台解码，一张大图不再卡住一帧；解码期间位置已经占好，擦除、缩放和 kitty 删除照常生效。
- 鼠标悬停终端链接只扫描指针所在的那一组软换行，输出刷屏时不再整屏回扫。
- 保存一台主机的改动只重新编码改过的那条记录，主机很多时保存更快。

## 修复

- 设置里 MCP 分组的标题和说明改成用户关心的说法，不再和周围的卡片挤在一起。
