## New features

- Terminal tab titles can show the connection name, the terminal's own title or the current path; a name you set yourself wins.
- Bundled terminal color schemes, with the dark and light looks each remembering their own and a search box.
- The snippet picker's groups start folded and search still finds snippets inside them; a command field under the list sends one line to the current terminal, every connected terminal or the ticked ones, with or without Enter.
- The AI assistant's Agent mode can pick local files to upload to an SSH host; a file over the attachment read limit points to the upload button.
- The host form has a jump route entry, and the host pickers of jump routes and port forwarding search by name, address, account, group and tag.
- Saved hosts can be edited straight from the tab menu.
- The latency readout can be docked as a toolbar item, with its position and order saved.
- A session name you type may repeat another tab's; the assistant's @ references still point at exactly one terminal each.
- Serial hosts have their own icon, selected when the form switches to the serial protocol.
- SFTP can delete several selected items at once.

## Improvements

- Grouped vertical tabs use the shared tree keyboard navigation; Up and Down no longer wrap at the ends.
- The "Proxies" page is now "Jump Routes", and a host's "Proxy forwarding" row is "Outbound proxy", so the two are no longer confused.
- Hovering the tray icon on Windows shows the product name and version.
- In right-click copy/paste mode, right-click copies selected text and pastes when nothing is selected; Shift+right-click opens the menu.

## Fixes

- Restoring from a file backup also restores custom shortcuts.
- Remote desktop supports RealVNC's RSA-AES authentication.
- The standalone MCP service mentions `sftp_download` in `sftp_read` only when transfer tools are offered, and says how to enable them.
- Canceling an upload on a network that has stopped answering no longer hangs.
