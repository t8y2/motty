# 配置同步范围

云端同步以记录为单位合并配置。“设置”是共享设置白名单，不代表把整份本机配置上传。WebDAV、S3、GitHub Gist 和 Gitee 使用同一套同步与恢复逻辑；同步内容由本机勾选的分类控制，默认全部开启。

## 会同步的内容

| 分类 | 内容 |
| --- | --- |
| 主机 | 连接与分组，以及该分类对应的保存密码 |
| 设置 | 下表中的共享设置、出站代理和命名代理配置 |
| 笔记 | 保存在 Motty 中的笔记与目录；链接到本机文件的笔记不上传 |
| 快捷命令 | 命令及其分组；本机快捷键绑定另行保留 |
| 代理路线、端口转发 | 保存的路线与转发定义 |
| 工作区 | 保存的工作区模板，不是当前窗口里正在运行的会话 |
| 凭据、密钥 | 对应分类的保存凭据、私钥及口令 |
| AI | 提供商配置及对应密钥 |
| 规则 | 高亮、自动填写、可同步的 SFTP 书签/位置配置 |
| 已信任主机 | `known_hosts` 中的已信任密钥 |

“设置”白名单包含：

| 范围 | 内容 |
| --- | --- |
| 主机列表 | 排序方式、隐藏标签 |
| 连接 | 超时、保活、重连策略 |
| 终端行为 | 滚动回看、剪贴板策略、选择复制、单词分隔、右键粘贴、标题方式、延迟显示、响铃、链接/输入点击行为 |
| 终端显示 | 明暗终端配色、内边距、装订边、亮色、行高、光标闪烁和粗细、内置日志级别高亮 |
| 提示与补全 | 通知、图片粘贴、密码提示、关闭确认、命令历史/补全/建议/接受提示的开关；不上传本机采集的命令历史数据库 |
| SFTP | 并发、预览大小、保留时间、跟随目录、路径输入、面板自动打开及侧边选择 |
| 工具栏 | 窗口、终端和 SFTP 工具栏的可见项与顺序；跨区域停靠与混排顺序；终端工具栏的位置和大小 |

工具栏布局、位置和大小作为一份 `setting/toolbars` 记录同步，避免从不同机器各取一部分而得到混合布局。关闭“设置”同步后，不会上传或接收这份记录。

## 仍按设备保存的内容

语言、界面主题与 Logo 配色、字体和字号、窗口位置与尺寸、当前会话与面板状态、侧栏布局、本地目录/下载目录/编辑器/终端路径、本机启动行为、系统代理模式，以及同步服务地址和登录信息等仍保存在本机。

文件备份还可以携带设备快捷键偏好；日常云端同步不交换这部分。同步服务本身的密码和令牌不会被放进它所存储的备份。

## 旧配置与备份兼容

- 打开旧配置时，将已定制的本机工具栏布局和位置、大小迁移为共享记录；未定制的默认值仍不上传。多窗口只迁移一次，未知的本机字段保留在本机。
- 已有共享工具栏记录优先；旧的位置和大小字段作为兼容镜像继续保留。
- 旧备份不包含工具栏共享记录。恢复它时保留目标机器当前的工具栏；新机器继续使用默认布局。旧备份里没有保存的信息无法凭空恢复。
- 主动重置布局会写入明确的默认配置，其他机器可以收到这次重置；一台从未配置过工具栏的新机器不会用默认值覆盖云端的自定义布局。
- 不改变备份封装版本或配置兼容 epoch。旧客户端保留并转发它不认识的共享记录，但需要升级才能应用新同步的工具栏配置。
