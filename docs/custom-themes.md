# 自定义主题

## 终端主题

打开「设置 → 终端 → 终端配色」，在主题卡片上右键操作；完整主题列表同样支持右键菜单。首页第三行固定显示最近创建的四个自定义主题，最新的位于最左侧；其余主题在「全部配色」中查看，选中不会改变顺序。「全部配色」默认显示全部，我的主题位于内置主题之前，支持「全部、内置、社区深色、社区浅色、我的」分类筛选，并可叠加名称搜索。

- 新建：点击配色列表标题旁的「新建主题」，可选择深色或浅色模板。
- 复制：复制右键点击的主题，不必先应用该主题。内置、社区及目录导入主题只提供复制。
- 编辑：修改右键点击的自定义主题，也可在编辑器中重命名。主题 ID 不随名称改变。
- 删除：确认后移除自定义主题，正在使用它的终端恢复默认配色。

编辑器支持背景、文字、光标、选区及 ANSI 16 色。点击任意色块，在该色块旁打开颜色选择器，选色即更新草稿和预览，无需在色盘中确认；通过编辑器「保存」或「保存并应用」统一提交；HEX、RGB 字段用于精确输入。背景不透明度只作用于底色，文字保持不透明。

编辑器右上角提供方框式最大化 / 还原与关闭图标，最大化后占满应用窗口的可用区域。宽窗口并排显示编辑区和实时预览；窄窗口通过「编辑 / 预览」切换。预览显示顶部多标签、最大化终端中的 `ls` / `ll` 输出和底部终端标签，并同步当前背景图、主题配色及不透明度；可展开查看。预览使用本地固定文本，不执行命令或连接服务器。

- 重置修改：恢复本次打开编辑器时的配色。
- 保存：保存主题；若正在使用该主题，现有终端同步刷新。
- 保存并应用：保存并选用该主题。
- 取消或关闭：丢弃草稿，不改变已保存的主题。

主题存入现有配置存储，随共享设置同步。原有 `schemes` 目录的 `.xresources` 文件仍可使用，编辑时创建独立副本。

## 界面主题

「设置 → 外观」支持系统、深色、浅色、自定义四种模式，并保留上游独立的「跟随终端」开关。

「跟随终端」沿用上游的 `appearance_follow_terminal` 设置和配色派生逻辑。在终端配色中切换主题时，选择始终写入 `terminal_scheme_dark/light` 并随共享设置同步。关闭开关不会恢复到旧配色。深浅色模式仍分别保存终端选择。

「自定义」提供背景、面板、正文、次要文字、强调色、边框等颜色。高级颜色允许覆盖悬停、按下及标签页状态。颜色选择器内的草稿在点击应用后生效。

界面背景不透明度独立于终端背景；存在背景图片或平台提供透明窗口时生效。没有透明支持及背景图片时，界面维持可读的实色背景。主题编辑器和确认弹窗保持不透明。

### 自定义外观的来源与优先级

首次进入「自定义」时，从当前终端主题生成界面配色快照（沿用上游配色派生，包含不透明度），已有手动覆盖项会保留。之后再次进入自定义会恢复已保存的自定义配置。

自定义模式下，切换、复制或编辑终端主题只改变终端；界面继续使用自定义配置。退出自定义并启用「跟随终端」后，界面颜色和不透明度随当前终端主题更新。自定义配置优先于跟随开关，离开自定义时恢复开关的效果。

早期 PR 保存的 `theme=terminal` 会迁移为原来的深色或浅色模式并启用现有跟随开关；设备本地的 `followScheme` 会写回对应的终端配色设置，迁移后不再保存旧来源字段。
