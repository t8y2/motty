## 目标与范围

- 做：在现有终端补全之上覆盖一份可审计的跨类别常用命令清单，显示命令、子命令、选项和说明；支持输入时自动候选列表、已选择主机的命令存在性探测，以及可选的选中项实时预览。
- 做：仅新安装默认关闭命令提示；现有配置没有独立模式记录时，无论过去是隐式还是显式 Both，均维持原有 Both 行为。旧版显式 Off/List 也保留。远端探测和实时预览各自额外选择开启；仅开启基础补全不会运行额外命令或改写行。
- 做：开启已有的主机探测开关后，按安全前缀发现静态目录之外的可执行命令名，并为受支持的 POSIX 路径参数提供文件/目录候选；在已知平台上避免明显错误的选项方言，优化常用根命令的中文说明和候选排序。
- 不做：自动执行补全候选、自动运行任意第三方命令的 `--help`、执行 Fig/Carapace 的脚本生成器、把 Netcatty GPL 代码移植进 Motty、持久化探测得到的主机清单、强制接管 shell 的 Tab。
- 不做：在 Telnet、串口、RDP 或未知 shell 上运行动态探测或改写输入；这些连接保留现有静态/历史候选能力及自然降级。

## 仓库现状

- `internal/completion` 是 UI 无关的离线 Carapace 目录、解析、审计与只追加匹配器；内置 v1.8.1 快照有 742 个根命令。当前 `cat`、`ls`、`kill` 根条目没有选项，`ip`、`ss`、`netstat` 缺根条目。
- `internal/workbench/completion.go` 负责历史与目录合并、Viva 光标弹层、手动触发、设置和候选选择；`completion_input.go` 用会话/终端/提示符/代次快照验证接纳，现有 Enter 仅追加后缀，Tab 转交 shell。
- `internal/sshconn/command.go` 的 `(*Conn).RunCommand(ctx, command, maxOutputBytes)` 使用独立 SSH command session、限输出并支持取消。`internal/workbench/local_terminal.go` 的 `(*localConn).RunCommand` 返回 `errLocalOnly`；本地探测需专属适配器。
- `internal/shellkind` 区分 POSIX、PowerShell、Cmd、Fish、Nushell 和 Unknown；shell 集成仅在可信提示符提供输入确认。设置通过 `savedState` 与 `persist_records.go` 的共享记录保存；当前缺省 Off/List/Both 中的 Both 与未表达偏好同为两个 false。

### 常用命令覆盖矩阵

| 类别 | 本轮必须有根命令及代表性选项/子命令的名称 |
|------|------------------------------------------|
| Unix 基础工具 | `cat ls cd cp mv rm mkdir chmod chown grep sed awk find head tail sort uniq cut wc tee xargs du df tar gzip` |
| 网络与系统管理 | `ssh scp rsync curl wget ping ip ss netstat ps kill top systemctl journalctl apt dnf yum` |
| 开发与平台工具 | `git docker kubectl make gcc go cargo rustc java javac npm yarn pnpm node python pip brew` |
| Windows shell 常用入口 | `pwsh powershell cmd dir Get-Command Get-ChildItem`；只有对应 shell 可用时才将适用性标为已确认 |

矩阵是一组可测试的初始下限，不是全部用户命令的封闭名单；开启主机探测后，可以发现匹配安全前缀、位于 PATH 的目录外可执行文件名，但不会发现 shell alias、函数或任意脚本生成的参数。未知语法、带引号/空格的路径和不支持的终端仍交由 shell 的 Tab。每项需在覆盖审计中标记“静态规格完整 / 仅名称 / 缺失”，未到完整不得宣称覆盖完成。

## 架构与边界

- 数据：`internal/completion` 保留 Carapace 目录和原子更新；一份随程序内置、可追溯的补充目录只填充明确缺失的常用规格，独立于用户更新目录，纯数据且经相同 SafeInsert 约束。常用清单按 Unix 基础工具、Git/容器/K8s、包管理/语言工具、网络/系统工具、Windows shell 工具分组；每个条目检查命令根及代表性选项/子命令，未覆盖项不得悄悄标为通过。
- 查询：`internal/workbench` 合并历史、补充目录、公共目录及已知可用性，按真实插入文本去重；已确认历史优先，已探测可用的命令高于未探测公共候选。无探测结果不等于不存在；未探测的公共命令必须标为参考建议。
- 探测：用户另行开启后，只有带支持的命令通道和已知 shell 家族的连接在后台执行固定、有界的命令存在性查询；标识符先校验，不拼接终端输入。独立本地适配器使用当前已配置的 shell 程序。2 秒超时、受限输出、同连接缓存及取消；失败/不支持则保留静态候选，不主张它代表交互 shell 中动态更改的 PATH、alias 或函数。
- 扩展查询：只在同一个主机探测开关开启时，对至少 2 个安全 ASCII 字符的命令前缀执行固定、2 秒超时、4096 字节输出、最多 64 名的 PATH 可执行文件查询；仅接纳与前缀匹配且能安全插入的名称，结果按连接、前缀和 TTL 管理，空静态目录也可等待异步结果。路径候选仅限受支持的 POSIX shell、已确认的普通提示符、明确的常见文件参数命令，以及无引号/转义/空格/控制字符的单个安全 token；相对路径以该会话可信 CWD 为准。远端和本地均通过固定、正确引用目录的只读 POSIX 脚本与已存在的有界可取消命令通道查询，不打开无 context 的 SFTP 会话；每次最多显示 64 项、4096 字节、2 秒超时。拒绝不安全文件名，失败仍保留静态候选与 shell Tab。
- 适用性与排序：历史候选继续优先；根命令中有本连接可用性证据的候选优先，其次为 65 项高频清单，再保留公共目录顺序。已知 CMD/PowerShell 不展示 Unix `dir` 选项，已知 POSIX 不展示 CMD `dir /A`；已知 macOS/BSD 的 `tail` 不提示未经验证的 GNU 长选项。未知平台保留“参考规格”而不声称适用。简繁中文至少覆盖 65 项根命令及本轮审计的补充选项说明；没有可靠翻译的公共目录词条保留原文，不机器臆译。
- UI：只有可信、非敏感且光标在行尾的普通终端提示符才自动弹出。光标弹层在窄分屏内钳制，候选行显示类型/来源，选中或悬停提供完整说明；手动快捷键、Tab 和 IME 行为保持原样。绘制时不访问磁盘、网络或启动 goroutine。
- 实时预览：单独开启且只在当前提示符由集成脚本报告 Ctrl-U 实际绑定为 Bash/Zsh 安全清行控件、并确认回显后生效；不明绑定、Vi 编辑模式和 Zsh 改写行初始化/键表钩子降级到普通候选。选中候选可将当前行改为预览行；下一次选择与 Esc 必须排空待解析输出，以已确认的当前回显为起点并恢复原行。输入竞态、超时、提示符变化或未知 shell 时停止后续改写并回退到非改写候选；不猜测远端真实行。首次 Enter 仅确认候选，不发送 CR；用户再次按 Enter 才执行。关闭连接、NoHistory、密码行、IME、AltScreen、广播与 AI 命令期间禁止预览。

## 数据与状态

| 实体 | 存储/键 | 类型 | 唯一性 | 状态 |
|------|---------|------|--------|------|
| 补全偏好 | 本机 `command_completion_default_off`、用户主动选择时的共享 `command_completion`，兼容旧 `command_suggest_off`/`command_inline_suggest_off` | 本机 bool、共享 Off/List/Both 枚举与旧 bool | 每设置一个记录 | 仅全新设备持久化本地默认 Off；旧配置无本地标记时按旧 bool 还原，两个 false 即 Both；用户主动选择写共享记录 |
| 自动弹层、探测、实时预览 | 分别为共享布尔偏好 | bool | 每设置一个记录 | 默认 false；关闭基础补全时均不工作 |
| 探测结果 | 会话内存 | available/unknown 与时间/连接代次 | 每连接与命令 | 加载、可用、未知、失效；不落盘 |
| 主机命令/路径候选 | 会话内存 | 前缀、可信 CWD、会话/连接代次与失效时间 | 每连接及查询 | 等待、成功、失败、失效；不落盘，不跨主机共享 |
| 预览 | 会话内存 | 基线、候选行、会话/提示符/回显代次 | 每活动终端最多一个 | idle、awaitingEcho、previewed、restoring；任何失配都失效 |

## 接口与数据流

| 方法 | 路径/事件 | 请求/载荷 | 响应/错误码 | 调用方 |
|------|-----------|-----------|-------------|--------|
| 本地方法 | `completion.Complete` | 离线目录与已确认行 | 有界候选或 Suppressed | workbench |

| UI 事件 | `completionCandidates` / `completionKey` / `completionInput` | 会话与提示符快照、用户按键 | 候选状态或拒绝写入 | Viva workbench |
| 无外部 API | 不新增 HTTP/RPC/数据库接口 | 无 | 无 | 无 |

## 用户故事与验收

### 用户故事 1 - 常用命令帮助（P1）

开启命令提示后，用户输入 `ca` 可看到 `cat`、`cargo` 等不同来源的命令；输入 `cat -` 可看到 `-b`、`-e`、`-n`、`-s`、`-t`、`-u`、`-v` 及完整说明。清单中的基础命令至少有可验证的根和代表性选项/子命令；不为目标平台虚构“已安装”。

### 用户故事 2 - 当前主机提示（P1）

用户主动开启主机探测后，SSH/本地 shell 的存在性结果可影响候选标识与排序；超时、命令通道不支持、连接切换或禁用设置不会改变终端命令行，也不丢失离线候选。

### 用户故事 3 - 安全预览（P1）

用户主动开启实时预览，在受支持的已确认提示符里用方向键可预览完整行，Esc 恢复原行；Enter 只确认、不执行。任何未确认回显或输入竞态都不应继续写入猜测的恢复序列。

### 用户故事 4 - 主机专有命令与路径（P1）

用户主动开启主机探测，在已确认的 SSH/本地提示符输入安全前缀时，即使静态目录没有这个命令，也能看到该主机 PATH 中匹配的可执行文件名。输入 `tail -f /var/lo` 等普通路径参数时，可看到当前主机相应目录内安全的文件/目录名；选中目录只补入目录名和分隔符，不执行命令。不存在的目录、被拒绝的额外命令通道、连接切换、输入继续变化或超时只保留静态建议，绝不把旧主机结果插入当前行。含空格、引号、转义或 shell 扩展的路径不在本轮自动建议范围，用户仍可按 Tab。

### 用户故事 5 - 平台与中文说明（P2）

同一用户切换到 CMD、PowerShell、Unix 或 macOS BSD 时，不会在已知不兼容的 shell 中被提示对应 `dir`/`tail` 方言选项；未知平台仍标为参考规格。简体和繁体中文界面下，65 项常用根命令与补充目录选项的说明使用本地审校文案。历史候选与已探测可用的命令不被静态高频排序压后。

### 边缘情况

- Off/旧配置迁移、NoHistory/敏感文本/IME/AltScreen、SSH 迟到输出、多窗格、Windows 字宽和窄窗口。
- 探测输出恶意/过长、超时/取消、单通道跳板机拒绝额外 SSH session、远端 PATH/壳层与独立探测 session 不一致。

## 功能需求

- **FR-001**：仅新安装 Off，并将 `command_completion_default_off` 存在设备本地而非云同步默认值；旧配置没有新标记时按两个旧布尔位原样解释为 Off/List/Both。用户主动选择才写共享 `command_completion`；三个新增开关默认 false 且可保存/恢复。
- **FR-002**：离线清单至少覆盖上述命令矩阵中的每项根及代表性选项/子命令；`cat -` 和其他缺失选项有安全、可追溯的补充目录，公共目录更新不抹掉补充数据。
- **FR-003**：自动列表须通过既有 completionEligible/Secret/NoHistory/IME/AltScreen 等门禁，候选与详情有界、无绘制期 I/O。
- **FR-004**：动态探测仅对用户开启、能力可用的 SSH 或本地 shell 运行固定脚本，限时限输出、取消安全、结果按连接失效；失败静态回退。
- **FR-005**：实时预览只有在已确认回显与可安全编辑的 POSIX shell 上写入；所有状态转移可复核，Esc 恢复基线，首次 Enter 不执行，其他 shell 无副作用降级。
- **FR-006**：候选详情在鼠标与键盘路径都可读，布局在 320x240 到常规桌面窗口不越界；中英界面文字齐全。
- **FR-007**：同一额外主机探测开关控制安全前缀的主机可执行文件发现；根命令无需预先存在于静态目录。固定脚本、64 项/4096 字节/2 秒上限、输入输出校验、连接/提示符代次与缓存失效必须可测，失败不阻塞静态候选。
- **FR-008**：受支持的 POSIX 文件参数命令在可信 CWD 下提供本地/SSH 只读路径候选，安全裸 token 和目录后缀可接受；命令通道不支持、无可信 CWD、敏感/复杂行或取消时降级 Tab，不能越权执行或写远端。
- **FR-009**：已知平台过滤明显错误的静态选项；简繁中文覆盖 65 项常用根命令与补充规格说明；历史、已确认可用、高频静态、其他参考候选依次排序且稳定。

## 错误、重试、幂等、鉴权

- 错误：探测失败不阻断用户输入，只显示静态候选；预览失配关闭并停止改写，不伪造已恢复状态。
- 重试：探测仅由新连接/明确刷新或有界缓存到期触发，不逐键重试；预览不自动重试失败的物理写入。
- 幂等：相同连接内相同候选的并发探测合并；接受与预览在等待回显期间不得重复追加。
- 鉴权：沿用已认证 SSH 连接；探测独立于 AI 命令审批但必须有用户选择的设置授权，NoHistory 主机不探测、不缓存私有候选。

## 测试策略

- 先写失败测试，再实现数据/设置、探测、自动弹层和预览；运行 completion/workbench/sshconn/localshell 聚焦测试、竞态与 Go vet。
- 用 Viva `vivahead` 的 headless session 对中英、明暗、窄/宽分屏、键盘与鼠标、输入/回显/失效流程执行无头验收和截图；工具不连接真实生产主机。
- 不把静态测试视为真实 SSH/Windows 产品验收；只在模拟与本机已知环境内报告通过。

## 成功标准

### SC-U（可观察）

- **SC-U001**：开启后 `ca`、`cat -`、常用类别代表性命令可得到候选与完整解释，关闭后没有自动弹层。
- **SC-U002**：主动启用探测后，可用性有证据时被标识；失败仍可用静态目录。
- **SC-U003**：预览、Esc、首次 Enter 与再次 Enter 的行为可由无头终端观察，不会在密码或全屏输入中触发。
- **SC-U004**：主机上独有且不在公共目录的测试可执行文件可由前缀发现；`tail -f /var/lo` 的安全路径候选可在本地和环回 SSH 呈现；无权限/取消/换主机无误插入。
- **SC-U005**：已知系统的 `dir`/`tail` 候选方言不误导，简繁中文的常用命令详情可读，`ca` 等宽前缀优先显示本机可用及高频命令。

### SC-T（技术可测）

- **SC-T001**：`completion.Complete` 对 `cat -` 返回上述至少 7 个安全选项，清单覆盖审计失败即测试失败。
- **SC-T002**：`(*sshconn.Conn).RunCommand` 的探测仅接收固定验证名、2 秒内取消并限制输出；过期结果不进入新连接。
- **SC-T003**：`completionKey`/`completionInput` 的快照失配时不写 shell；预览恢复只有在匹配回显时发送，Enter 不含 CR。
- **SC-T004**：`go test` 的真实 `vivahead` 帧在 320x240 和 900x600 无不可读候选/遮挡，截图和键盘流通过。
