## Coverage Audit

`TestCommonCommandMatrixHasRepresentativeSyntax` walks all 65 required roots across Unix basics (25), network/system (17), development/platform (17), and Windows shell (6). It treats a described, safe root plus at least one described option/subcommand from the built-in or supplemental catalog as **complete**. Result: **65 complete, 0 name-only, 0 missing**. This is a syntax coverage floor, not proof that any root exists on the connected machine. `TestCommonWindowsSuggestionsUseRealOptionSpelling` checks `-NoProfile`, `/C`, `/A`, `-Name` and `-Path`; `TestCommonCatalogKeepsSevenCatOptions` checks seven `cat -` choices. Updating the public catalog does not remove the separate supplement.
