# Symbols Nerd Font Mono

`SymbolsNerdFontMono-Regular.ttf` is the icon-only face of Nerd Fonts
NerdFontsSymbolsOnly v3.4.0. It carries the private-use glyphs terminal
programs print (Powerline separators, Devicons, Font Awesome, Octicons and the
like), and no reading text.

- Source: https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.4.0
- Archive: `NerdFontsSymbolsOnly.zip`
- SHA-256: `f0f624d9b474bea1662cf7e862d44aebe1ae1f6c7f9cb7a0ca5d0e5ac9561c60`
- License: MIT, see `LICENSE` in this directory.

The binary embeds the file as `assets.SymbolsNerdFontMono`; the application
registers it for the process at startup. It is never installed into the system
font library.
