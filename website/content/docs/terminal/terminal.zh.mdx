## 终端模拟

真正的 PTY 会话，支持：

- 256 色和真彩色输出，
- 备用屏幕，
- 5000 行回滚缓冲，
- 宽字符和组合字符，
- 鼠标上报，
- 输入法，
- 随 pty 变化的窗口大小，
- 同步更新（DECSET 2026），全屏重绘一次呈现，
- kitty 键盘协议，包括按键释放和 Esc/Alt 消歧，
- Windows 本地 shell 的 win32-input-mode，
- 连字：在固定网格中按单元格整形。

## 协议

同步更新（DECSET 2026）会保持上一帧，直到程序结束这个块，因此全屏重绘一次呈现；
如果程序一直不结束，一秒后会释放。kitty 键盘协议支持消歧、事件类型、Shift 备用键、
全部按键转义码和关联文本，主屏和备用屏各有独立栈。win32-input-mode 只在 Windows
本地 shell 提供。连字取决于所选字体，并按单元格跨度适配。

## 标签页与分屏

标签页可以重新排序、水平或垂直分屏、在窗口之间移动，并且无需重新连接即可恢复。这些
操作都是命令面板里的命令。

## 搜索与链接

用 **Command+F**（其他平台为 **Control+F**）搜索保留的历史输出。可以在终端里打开
HTTP、HTTPS 和 OSC 8 链接。

## 图片

内联渲染 Kitty、iTerm2 和 SIXEL 图片。

## 片段与广播

向会话发送保存的片段，或在分屏标签页的各个窗格之间广播输入。

快捷命令不必设置快捷键：在侧边栏「快捷命令」页面选中它后点「发送到终端」，或双击该行，
或右键该行使用「发送到终端 / 编辑 / 删除」菜单。只打开一个终端时直接发到该终端；有多个
终端（标签页或分屏窗格）时会弹出终端列表供你选择目标，当前活动的标「当前」，发送后会切到
所选终端，状态栏会写明发往哪个终端。命令列里的 **↵** 键帽表示
发送后会自动按回车。

## 命令历史

**Command+Shift+H**（其他平台为 **Control+Shift+H**）打开你在终端里输入过的命令。

## 命令补全

**Command+Shift+J**（其他平台为 **Control+Shift+J**）会列出可以接在当前输入后面的命令、
子命令、选项和固定的选项值，数据来自 Motty 内置的命令库。回车只插入缺少的部分，
不会执行。在“设置 > 终端”中可选择 **关闭**、**列表** 或 **列表+内联**，后者还会在输入时
以灰字显示建议。补全不需要开启“记住命令”，**检查更新** 可按需刷新命令库。

## 外观

内置配色方案加整套社区配色合集；把 X resources 配色文件放进数据目录的
`schemes` 文件夹即可加入自己的方案，搜索框按名称查找。深色和浅色外观各记住
一套。关键字高亮和可配置的字体也在同一页。字体只保存在本机，不参与同步。

## 录制

只有你主动开始录制时才会录制会话。

## 终端内的传输

远端 `sz` 或 `rz` 开始时，ZMODEM 传输随之开始；XMODEM 和 YMODEM 从终端菜单发起。
见 [ZMODEM、XMODEM 与 YMODEM](/zh/docs/files/zmodem-xmodem)。
