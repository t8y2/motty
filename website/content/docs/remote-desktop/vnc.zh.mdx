远程桌面主机会作为一个标签页打开，显示的是画面而不是终端。

## 支持

- RFB 3.3、3.7 和 3.8；RealVNC 的 5.0 标识会协商为 3.8
- 安全类型 None、VNC Authentication 和 RealVNC RA2（RSA-AES，类型 5）
- 编码 Raw、CopyRect、RRE、Hextile 和 ZRLE
- 桌面尺寸变化
- 指针、键盘和文本剪贴板

## RealVNC 系统账户

RealVNC 服务端使用 **Always on** 加密和 **UNIX password** 认证时，可以使用 RA2。
在 VNC 主机的可选用户名字段填入系统账户，或在连接时输入用户名和密码。

输入凭据前会显示服务器密钥确认。已保存的密钥发生变化时会停止连接。
公开密钥指纹随主机配置保存，参与备份、同步、复制和删除。
系统账户密码与传统 VNC 密码分别保存，登录后的桌面通信继续加密。

## 通过 SSH 连接

<Callout type="warn">
  VNC Authentication 很弱：DES 加密，密码最多八个字符，挑战值以明文穿过网络。标签页会
  显示“未加密”。
</Callout>

请使用 **通过 SSH 连接**。此时主机地址指的是 SSH 服务器。Motty 会使用地址和账户相同的
已保存 SSH 主机（沿用其端口、算法和跳板路由），否则使用 22 端口的普通 SSH，先问完 SSH
的问题，再通过 `direct-tcpip` 通道从 SSH 服务器连接 `127.0.0.1:<端口>`。

## 在标签页里

- 适应窗口或 100% 缩放；100% 时，较大的画面随指针平移。
- 画面获得焦点时，Motty 的快捷键不会触发，按键都发给远端。**Ctrl+Alt+G** 释放键盘，
  再按一次重新接管。
- 状态栏显示远端尺寸、缩放、“通过 SSH”、VNC 加密或“未加密”、剪贴板共享状态和退出组合键。
- 连接丢失后会保留最后一帧画面并调暗，同时给出重新连接按钮。

## 剪贴板

按主机设置，默认关闭，仅限文本。RFB 使用 Latin-1，其他字符会以 `?` 发送。

## 不支持

RA256、RA2ne/RA256ne、VeNCrypt/TLS、Apple Remote Desktop 认证（macOS 屏幕共享需要开启“VNC 查看器可使用密码
控制屏幕”）、Tight/JPEG、扩展剪贴板、剪贴板图片、音频、文件传输、修改远端分辨率和多
屏幕。KasmVNC 无法使用，因为它按非标准格式读取指针事件；TigerVNC 和任何遵循 RFC 6143
的服务器都可以。
此 RSA-AES 实现不支持其他 RealVNC 安全方式，包括仅提供类型 13 的服务器。

## 验证情况

已在 Linux 机器上的 KasmVNC `Xvnc` 和 Docker 中的 TigerVNC 上验证，包括通过 SSH 隧道。
仍需手动验证：原生窗口中的物理键盘与鼠标操作、输入法组合输入、被隐藏或被遮挡的窗口、
macOS 屏幕共享，以及 Windows 上的 VNC 服务器。
另已对 RealVNC Server 7.13.1.57 验证版本协商、RSA-AES 服务器证明和系统账户认证选择，
验证时没有发送用户名或密码。
已通过 Windows 客户端实测树莓派系统账户登录、桌面显示及剪贴板共享。
中文仍受 Latin-1 剪贴板限制。该服务器上的重新连接、长时间使用，以及最新密码和服务器密钥保存变更仍需手动验证。
