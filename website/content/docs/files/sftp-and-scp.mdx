description: Browse, transfer and edit remote files.

Open the file panel with **Command+Shift+S** (**Control+Shift+S** elsewhere).

## Browsing and transfers

- Multi-select, recursive upload and download.
- A bounded transfer queue with resume, cancel and retry.
- Rename, delete, permissions and bookmarks.

Select **Input field** under **Settings → Files → Path bar style** to replace the breadcrumbs with an editable path.
Enter an absolute path or a path relative to the current folder and press Enter to navigate;
press Escape to restore the current path. This applies to both remote and local file panels.
Breadcrumbs remain the default.
Navigation failures appear in a global toast at the top of the window, including the requested path.
The current folder and typed path are preserved so you can correct the path and try again.

## Transfer center

The transfer icon to the left of the AI assistant collects SFTP and SCP tasks from every connection in the current window.
Its badge shows the number of active tasks. Queuing an upload or download opens the popover automatically;
click outside, press Escape or use its close button to dismiss it.

Filter active and finished tasks and inspect their server, filename, time, progress, size and speed.
Sizes and speeds scale automatically to KB, MB, GB and larger units. Pause, resume, cancel or retry tasks,
or remove finished history without deleting files. Transfers continue when the file panel is hidden or another
session or page is selected. Closing a connection cancels its unfinished tasks; history lasts until the client exits.

## Safe replacement

Replacing a file stages a partial copy, verifies resumed prefixes and renames it
into place atomically, only after a complete synced copy exists. If anything
fails, the previous file stays intact.

## The editor

A native editor opens UTF-8 files up to 1 MiB. It hashes the remote file before
and after staging, so a file that changed on the server in the meantime is
noticed, and it preserves permissions.

## SCP fallback

Servers without SFTP can use the built-in SCP fallback.
