title: ZMODEM、XMODEM、YMODEM 与 TRZSZ

有些设备只能通过终端本身传文件。

## ZMODEM

远端 `sz` 或 `rz` 开始时，传输随之开始。Motty 把这段数据流从屏幕上接管过来，显示进度
对话框，结束后让终端恢复正常。

## TRZSZ

TRZSZ 是和 `rz`、`sz` 用法相近的较新传输工具，另外支持目录传输和自己的进度显示。在
远端运行 `trz` 或 `tsz`，Motty 会应答它的通告并显示同一个接收/发送对话框。`trz -d`
和 `tsz -d` 用来传目录。远端需要安装 trzsz（`trz` 和 `tsz`）。

## XMODEM 与 YMODEM

这两种协议不会在数据流里自报身份，所以要你从终端菜单发起：选择协议（XMODEM 校验和、
CRC 或 1K，或 YMODEM 批量）和方向，并自己在另一端启动对应程序。之后的传输和 ZMODEM
一样。

## 对端不能做什么

来自对端的一切都按不可信处理。文件名会被还原成纯文件名，声明的大小不会触发分配，对端
不能选择路径，也不能让 Motty 执行命令。TRZSZ 的目录会在 Motty 选定的名字下创建，对端
送来的每一段路径都会先检查再拼接。
