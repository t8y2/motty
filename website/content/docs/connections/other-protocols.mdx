---
title: Serial, Telnet and local shell
description: Other kinds of tab that behave like an SSH session.
---
A terminal tab does not have to be SSH. These sessions use the same terminal.

## Serial

A serial tab opens a port with the line settings you choose, and lists the ports
the machine has. For devices that move files with XMODEM or YMODEM, see
[ZMODEM, XMODEM and YMODEM](/en/docs/files/zmodem-xmodem).

## Telnet

For devices that offer nothing else. The client negotiates the options a terminal
needs: remote echo, suppress go-ahead, terminal type, window size and binary.

<Callout type="warn">
  Telnet is not encrypted and has no authentication of its own. Everything you
  type travels in the clear.
</Callout>

## Local shell

Runs your login shell on a pseudo-terminal of this machine: a pty on macOS and
Linux, ConPTY on Windows.

On Windows, PowerShell, CMD, Git Bash and every installed WSL distribution can
be used side by side, one per tab. The new-tab list (the `+` in the title bar) has
one "Local Terminal" row; its arrow expands the complete shell list under the
same search field, which keeps filtering it. A right-click on Local Terminal in
the sidebar, title bar or new-tab page opens the same list. The list starts
collapsed, so saved hosts are not pushed below every shell. **Settings → Terminal →
Default local shell** only decides what a plain click on Local Terminal starts.
A tab keeps its own shell through reconnects, duplicates and restarts. A WSL
distribution opens the terminal inside it, with the file panel following the
terminal's folder through the distribution's `\\wsl.localhost` share. Typing `wsl` into a PowerShell terminal still works as a
terminal, but the file panel cannot follow it: only a shell Motty starts itself
reports its folder.
