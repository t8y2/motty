## 主机密钥

发送任何凭据之前，Motty 都会用自己的 `known_hosts` 校验主机密钥。遇到未知主机会弹出
带指纹的对话框，你可以信任一次或保存。密钥变化时会再次提示。

## 认证

Motty 支持：

- 正在运行的 SSH agent 中的密钥，
- 身份文件和保存在 Motty 中的密钥，包括 OpenSSH 用户证书（导入密钥旁的 `-cert.pub` 会一起保存；在密钥链中用「证书」添加或更新），
- PuTTY `.ppk` 文件（版本 2 和 3，含 Argon2id 加密），
- 密码，
- keyboard-interactive 多轮问答。

一轮问答里有多个问题时（例如同一个 PAM 栈同时要密码和一次性验证码），会合并成一个
对话框，每个问题一个输入框。

### Kerberos（GSSAPI）

在主机的「认证方式」里选择「Kerberos（GSSAPI）」，即可登录支持 `gssapi-with-mic`
的服务器。macOS、Linux 和 Windows 都支持此选项：

- **macOS**：使用系统中已有的 Kerberos 凭据。
- **Linux**：连接开始时加载系统的 `libgssapi_krb5`，因此需要安装发行版的 Kerberos
  客户端库，并用 `kinit` 获取票据。Motty 读取默认凭据缓存，或 `KRB5CCNAME` 指定的缓存。
- **Windows**：通过 SSPI 使用当前已登录 Windows 账户的 Kerberos 票据。

票据过期后，请按平常的 Kerberos 登录流程续期。凭据委派处于关闭状态。

### 私钥

选择「私钥」认证时，认证只使用你选定的密钥；未选定密钥时，依次尝试密钥链中的密钥和
`~/.ssh` 下的默认密钥。服务器接受该密钥后，如果继续要求 OTP 或其他 keyboard-interactive
二次认证，Motty 会弹出问答框，或使用已保存的一次性验证码。服务器拒绝所有候选密钥，或所选
密钥已不可用时，认证失败，不会回退到交互式登录。

**密钥链 > 添加密钥** 有三种方式：**从文件导入**（密钥和旁边的 `-cert.pub` 证书一起
存进保险库）、**粘贴私钥**（不需要先有文件）和**生成新密钥**（一对 Ed25519 密钥，公钥会
自动复制，用于添加到服务器的 `~/.ssh/authorized_keys`）。所有密钥都加密保存在保险库中，
会随保险库同步到你的其他电脑。**复制公钥**可随时复制所选密钥的公钥；**证书**可为所选
密钥添加或更新 OpenSSH 用户证书。删除保存在 Motty 中的密钥无法恢复，因为没有文件可回退。

### 证书与 agent

服务器出示主机证书时，只要其证书颁发机构已以 `@cert-authority` 记录在案就直接
连接；未知证书像未知主机密钥一样弹出指纹确认。主机还可以把本地 ssh-agent 转发给
远端 shell（按主机开关，默认关闭），远端的 `git push` 或 `ssh` 就能用本机已加载
的密钥。

### 一次性验证码

TOTP 和 HOTP 种子可以存进保险库，服务器要求验证码时自动填入。

### 测试连接

主机表单里有「测试连接」按钮，按表单当前填写的内容拨号，不保存主机。测试不会信任
未知的主机密钥，也不会向这样的服务器发送任何内容；登录需要表单之外的信息（例如一次性
验证码）时，结果是「未验证」，而不是失败。

## 登录之后

主机的「登录后命令」（在高级选项里）会在每个新终端准备好接收输入后自动输入，效果和
你手动输入一样，例如 `cd /srv/app` 或 `sudo -i`。它只能是一行，不会进入命令历史。

要切换到 root，可以把 `sudo -i` 设为登录后命令，再为密码提示添加自动填充规则：
「设置 > 终端 > 自动填充规则」里有「sudo 预设」（用该主机已保存的密码回答）和
「su 预设」（用保险库里的固定文本回答，例如 root 密码）。规则默认关闭，每个会话第一次
发送之前会先询问一次。

## 整理主机

主机可以分组、打标签和搜索。

### 导入

点击**导入 > 从其他软件导入**，选择来源客户端，再选取它保存的文件或文件夹。Motty 读取每个
会话的名称、文件夹、地址、端口和用户；打不开的协议会计入“已跳过”。Electerm 和
Netcatty 的导出还可能含可读取的 SSH 登录密码，此时可以选择存入 Motty 保险库，
或只导入连接。Tabby 的私钥和保险库导入方式见下文。名称、地址、用户和端口均相同的
主机只会创建一次。导入的密码只补齐空缺，已有密码会保留。

| 来源 | 要选择的文件 |
| --- | --- |
| OpenSSH 配置 | `~/.ssh/config`（**导入 > 导入 SSH Config**） |
| PuTTY | Windows 上选注册表导出：`reg export HKCU\Software\SimonTatham\PuTTY\Sessions putty.reg`；Linux 和 macOS 上选 `~/.putty/sessions` 里的文件。 |
| Xshell | `.xsh` 会话文件，或 Xshell 导出的 `.xts` 压缩包。 |
| MobaXterm | 从会话面板导出的 `.mxtsessions` 文件，或 `MobaXterm.ini`。 |
| WindTerm | WindTerm 配置目录下 `terminal` 文件夹里的 `user.sessions`。 |
| Electerm | 在 Electerm 书签管理里导出的书签 JSON。 |
| Netcatty | Netcatty 主机页**导出**按钮得到的 CSV。Netcatty 自己的保险库是加密的，只有这份导出能被读取。 |
| FinalShell | FinalShell 的数据文件夹：Linux 为 `~/.finalshell`，macOS 为 `~/Library/FinalShell`，Windows 上通常是 FinalShell 的安装目录。 |
| Xterminal | Xterminal 的数据文件夹：macOS 为 `~/Library/Application Support/XTerminal`，Windows 为 `%APPDATA%\XTerminal`，Linux 为 `~/.config/XTerminal`；免安装版的数据在 `xt_data\userData` 下。 |
| XPipe | XPipe 的数据文件夹（`~/.xpipe`）或其下的 `storage` 子目录，也可以是它同步用的 git 仓库副本。导入 SSH、RDP 和 VNC 连接，XPipe 的其他条目类型不导入。 |
| Tabby | `config.yaml`，macOS 位于 `~/Library/Application Support/tabby`，Windows 位于 `%APPDATA%/Tabby`，Linux 位于 `~/.config/tabby`。 |

Tabby 导入会保留 SSH 主机和多级分组。使用跳板或代理的主机会跳过，需要在 Motty 中另行配置路由。
选择**保存本地凭据**可以把本地私钥、配套用户证书和 Tabby 配置文件中的 SSH 密码存入 Motty 保险库。
选择**仅导入连接**会保留对原私钥文件的引用。系统钥匙串中的密码和口令可在 Motty 首次需要时输入。

选择单个 Tabby 配置文件后，Motty 会检测其中的 Vault，并提供本机解锁。主机配置可直接读取时，
可以选择**跳过解锁**。如果 Tabby 加密了整份配置，解锁后即可读取 SSH 主机列表。
Motty 会预览可保存的 SSH 登录密码数量，只补齐匹配主机的空缺密码。
Tabby Vault 内的私钥和私钥口令需要另行配置。

Electerm 和 Netcatty 会把已保存的密码以明文写进导出文件。选择保存密码后，
合格的 SSH 密码进入 Motty 保险库，但源文件不会被删除；用完请妥善保管或删除。
Xterminal 和 XPipe 会加密已保存的密码和密钥，因此导入它们的数据文件夹只会得到连接，不会带走密码或密钥。
MobaXterm 的 UTF-8、带 BOM 的 UTF-16 和 GB18030 文本可读取；
不支持或损坏的编码会报错，不会静默丢字。无 BOM 文件若同时符合 UTF-8 和
GB18030，Motty 会先展示两种名称供选择，在确认前不会保存主机。
多文件中出现编码歧义时，请逐个导入，以便分别选择正确的编码。

## 与 SSH 配置同步

导入只读取一次文件。要让 `~/.ssh/config` 和 Motty 双向保持一致，请打开
**设置 > 连接 > 与 SSH 配置同步**。

- 你在文件里新增或修改的 `Host` 会出现在 Motty，在 Motty 里新增或修改的主机会写回
  文件。服务于 Git 而不是 shell 的区块（用户为 `git`，或指向 `github.com` 这类公共托管平台）
  不是可打开的主机，会保持原样并在同步结果里列出。
  主机地址、用户、端口和 `ProxyJump` 双向同步；`IdentityFile` 只会加入一次密钥串。
  `ProxyCommand` 只在主机第一次进入 Motty 时带过来，并等你确认（见
  [出站代理](/zh/docs/network/port-forwarding#出站代理)）。
  在 Motty 里停止跳板路由只影响 Motty 自己的连接；文件里仍保留 `ProxyJump`，终端里的
  `ssh` 依旧会经过跳板。
- 在 Motty 里创建的主机写进由 `# --- motty: begin synced hosts` 和
  `# --- motty: end synced hosts` 围起来的区块，位置在你的通用 `Host *` 区块之前。
  文件里的其余内容，包括注释和 Motty 不认识的设置，都保持原样。你自己写的主机在原处
  修改，并且只在它的区块只写了这一台主机时才会修改。
- 上次同步之后同一个字段在两边都被改过时，保留文件里的值。把主机从文件里删掉，它会
  留在 Motty 里并停止同步；在 Motty 里删除主机，会删掉 Motty 写的区块，而你自己写的区块保留。
- Motty 第一次改写某个文件时，会在它旁边保留一份以 `.motty-backup` 结尾的副本。写入
  过程中文件被别处改动时，绝不会覆盖。
- 同步发生在启动时、主机变化时，以及文件变化后你在窗口里点击时。不会轮询文件。
  **立即同步**可以随时手动运行，并列出无法映射的内容。

主机与别名的对应关系只保存在本机，不会随[云同步](/zh/docs/data/backup-and-sync)传到其他电脑。

## 保险库

保存的密码和密钥口令放在 AES-256-GCM 保险库里。保险库密钥保存在系统的密钥存储中；
如果设置了主密码，则由 Argon2id 主密码保护。保险库数据如何离开本机见
[备份与同步](/zh/docs/data/backup-and-sync)，安全模型见[安全](/zh/docs/reference/security)。
