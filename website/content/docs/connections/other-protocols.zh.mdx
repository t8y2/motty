终端标签页不一定是 SSH。这些会话使用同一个终端。

## 串口

串口标签页按你选择的线路参数打开端口，并列出本机已有的端口。设备如果用 XMODEM 或
YMODEM 传文件，见 [ZMODEM、XMODEM 与 YMODEM](/zh/docs/files/zmodem-xmodem)。

## Telnet

用于只提供 Telnet 的设备。客户端会协商终端需要的选项：远端回显、抑制 go-ahead、终端
类型、窗口大小和二进制。

<Callout type="warn">
  Telnet 不加密，自身也没有认证。你输入的所有内容都以明文传输。
</Callout>

## 本地 Shell

在本机的伪终端上运行你的登录 shell：macOS 和 Linux 用 pty，Windows 用 ConPTY。

在 Windows 上，PowerShell、CMD、Git Bash 和每个已安装的 WSL 发行版可以同时使用，
每个标签各跑各的：点标题栏的 `+` 新建标签时，列表里只有一行“本地终端”；
点这一行末尾的箭头，会在同一个搜索框下方展开完整 Shell 列表并继续支持输入筛选；
右键侧栏、顶栏或新标签页里的“本地终端”也能打开同样的列表。默认不展开，主机不会被
每个 Shell 挤到后面。**设置 → 终端 → 默认本地 Shell** 只决定直接点“本地终端”时用哪个。
标签记住自己的
Shell，重连、复制标签和重启后恢复都沿用它。选 WSL 发行版后，终端直接在该发行版里打开，
文件面板通过发行版的 `\\wsl.localhost` 共享跟随终端所在目录。在 PowerShell 终端里手动输入 `wsl` 仍然
可以用作终端，但文件面板无法跟随：只有 Motty 自己启动的 Shell 才会上报所在目录。
