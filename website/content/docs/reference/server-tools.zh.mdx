---
title: 服务器工具
description: 已连接服务器上的进程、Docker 容器和资源使用情况。
---
通过已认证的 SSH 连接，Motty 可以列出并操作服务器上的进程和 Docker 容器，也可以显示它的
资源使用情况。资源监控需要你主动开启：从终端里启动。

从终端右键菜单打开“远程工具”，会显示可移动、缩放的独立窗口。查看进程或管理 Docker
期间，主窗口仍可输入命令、切换连接和操作文件。同一会话重复打开会聚焦已有工具窗口，
不同会话可各自打开一个。

窗口标题会标明连接名称与地址，操作始终对应打开它的会话。终止进程、删除资源等确认仅在
工具窗口内显示。日志、拉取镜像的输出仍显示在原会话终端，容器终端会在原会话所在主窗口
新建标签页。关闭工具窗口会取消尚未完成的查询，不会断开 SSH；关闭或断开原会话也会关闭
对应的工具窗口。列表仍需手动刷新。

Motty 为此执行的每条命令都是固定文本。变化的只是一个数字或经过校验的容器名，绝不是自由
文本，因此服务器输出的内容和你输入的内容都不可能变成 shell 语法。
