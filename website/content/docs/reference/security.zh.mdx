## Motty 做了什么

- 发送任何凭据之前都会先校验主机密钥。
- 保存的密码和口令放在 AES-256-GCM 保险库里。它的密钥在系统密钥存储中，或由 Argon2id
  主密码包裹。
- AI 服务商密钥在保险库里。终端上下文默认脱敏，Agent 的命令都要经过审批门。
- MCP 服务器默认关闭，仅回环，并有 bearer 令牌保护。
- MCP 客户端按你选择的访问级别读取本机笔记库；**全部允许**还会让它们编辑笔记，并写入
  已经关联为笔记的 Markdown 文件。
- RDP 证书只有在你明确做出信任决定之后才会被固定。
- Motty 没有任何统计分析。可选的更新检查会访问 GitHub Releases，默认关闭。

## 它不做什么

审批门是一种安全控制，不是沙箱。VNC Authentication 和 Telnet 本身都不安全，请用 SSH 来
承载它们。Linux 安装包未签名。

## 报告漏洞

请使用仓库上 GitHub 的私密漏洞报告功能。不要把凭据、主机名和终端输出放进公开 issue。
