## Motty 做了什么

- 发送任何凭据之前都会先校验主机密钥。
- 保存的密码和口令使用 AES-256-GCM 加密。默认保险库使用系统密钥存储或本地密钥文件。开启应用锁定后，保险库使用由资料密钥派生的独立密钥。
- AI 服务商密钥在保险库里。终端上下文默认脱敏，Agent 的命令都要经过审批门。
- MCP 服务器默认关闭，仅回环，并有 bearer 令牌保护。
- MCP 客户端按你选择的访问级别读取本机笔记库；**全部允许**还会让它们编辑笔记，并写入
  已经关联为笔记的 Markdown 文件。
- RDP 证书只有在你明确做出信任决定之后才会被固定。
- Motty 没有任何统计分析。可选的更新检查会访问 GitHub Releases，默认关闭。

## 应用锁定

在 **设置 → 安全 → 应用锁定** 中开启主密码保护。输入两次主密码，等待迁移完成。
左下角本地终端上方会出现锁屏按钮。它会锁定同一资料目录的所有窗口，已有连接继续运行。在锁定期间新开的窗口也需要解锁。重新启动后，输入主密码或使用已登记的系统凭据即可恢复工作区。

主密码保护本机配置数据库中的连接资料和保险库中的凭据。请妥善保存主密码，迁移到新电脑时需要用它解锁。
支持的设备可以另外登记 Windows Hello 或 macOS 系统验证。系统验证由本机管理，主密码在两种解锁方式下都可使用。
修改密码或关闭保护时需要验证当前主密码。修改密码会重新封装资料密钥。关闭保护会将连接资料迁回普通配置，并用普通保险库的密钥重新加密已保存的凭据。若迁移中断，请重新打开 Motty 并用主密码恢复。

连接配置和凭据按记录加密。记录类型、同步时间戳、删除标记及锁屏所用的语言和外观偏好可见。命令历史（`history.db`）、AI 数据库（`ai.db`）、SSH 已知主机、远程桌面证书信任记录、会话日志、外部私钥和此前导出的备份仍按各自的方式保存。
导出的备份继续使用导出时设置的密码。迁移时保留的本地历史副本使用归档时的主密码，修改主密码后请留存这些副本对应的旧密码。
如需取回某份历史副本，可在终端运行 `motty recover-profile-backup <归档路径> <新目录>`，按提示输入归档时的主密码。命令将原文件和该副本需要的密钥材料写入新目录。单个历史副本超过 128 MiB 时，迁移会在更改现有资料前提示处理该副本。

## 它不做什么

审批门是一种安全控制，不是沙箱。VNC Authentication 和 Telnet 本身都不安全，请用 SSH 来
承载它们。Linux 安装包未签名。

## 报告漏洞

请使用仓库上 GitHub 的私密漏洞报告功能。不要把凭据、主机名和终端输出放进公开 issue。
