## Motty 做了什么

- 发送任何凭据之前都会先校验主机密钥。
- 保存的密码和口令使用 AES-256-GCM 保险库。保险库密钥由系统凭据存储或本地密钥文件保管。
  仍使用旧版保险库密码的用户，可在「设置 → 安全 → 已保存的密码」完成一次转换。
- AI 服务商密钥在保险库里。终端上下文默认脱敏，Agent 的命令都要经过审批门。
- MCP 服务器默认关闭，仅回环，并有 bearer 令牌保护。
- MCP 客户端按你选择的访问级别读取本机笔记库；**全部允许**还会让它们编辑笔记，并写入
  已经关联为笔记的 Markdown 文件。
- RDP 证书只有在你明确做出信任决定之后才会被固定。
- Motty 没有任何统计分析。可选的更新检查会访问 GitHub Releases，默认关闭。

## 应用锁定

在 **设置 → 安全 → 应用锁定** 中设置至少 6 个字符的主密码。左下角本地终端上方会出现锁定按钮，也可以按 `Ctrl+Shift+L`（macOS 上为 `⌘⇧L`）。锁定会遮住同一资料目录的所有 Motty 窗口。重启后先解锁，再恢复工作区。

可在同一组设置中修改密码，或在受支持的设备上启用 Windows Hello、Touch ID 或系统密码解锁。系统验证取消或失败后，仍可输入主密码。系统解锁可以直接在设置中关闭。

应用锁定保护 Motty 界面。主密码只用于本地校验，连接配置和保险库沿用各自原有的存储方式。能直接访问资料目录的程序仍可按原有权限读取配置。

## 它不做什么

审批门是一种安全控制，不是沙箱。VNC Authentication 和 Telnet 本身都不安全，请用 SSH 来
承载它们。Linux 安装包未签名。

## 报告漏洞

请使用仓库上 GitHub 的私密漏洞报告功能。不要把凭据、主机名和终端输出放进公开 issue。
