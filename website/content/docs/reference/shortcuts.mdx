The defaults use Command on macOS and Control on Windows and Linux. Every shortcut
can be changed in settings.

Tab switching wraps around at either end and repeats while the keys are held. Shortcuts
can use any combination of modifiers or none, such as `Alt+J`, `Shift+Enter` or `F8`.
Supported keys include letters, digits, punctuation, Space, Tab, Enter, Backspace,
Delete, arrows, Home/End, Page Up/Down, Insert and F1–F12.
Press Esc to cancel recording and click Delete to remove a binding; Esc can itself
be bound with modifiers. Duplicate bindings report a conflict. Bound keys take priority
over terminal input; combinations without Control/Command leave ordinary text fields editable.
Restore defaults in the capture dialog resets only that shortcut; the page header resets
all shortcuts. Resetting one shortcut reports a conflict if its default is already in use.
Command+1 to Command+9 on macOS, and Control+1 to Control+9 on Windows and Linux,
jump straight to the first through ninth tab. On Windows and Linux, when no tab sits
at that position the key stays with the terminal, where Control plus a digit can be
a control code.

Clearing the screen also drops the scrollback above it, but the line the cursor
is on stays, so a command being typed is not lost.

Inside a remote-desktop tab Motty's shortcuts are suspended and keys go to the
remote. **Ctrl+Alt+G** releases the keyboard.
