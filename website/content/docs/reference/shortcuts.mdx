can be changed in settings.

Tab switching wraps around at either end and repeats while the keys are held. Shortcuts
can use any combination of modifiers or none, such as `Alt+J`, `Shift+Enter` or `F8`.
Supported keys include letters, digits, punctuation, Space, Tab, Enter, Backspace,
Delete, arrows, Home/End, Page Up/Down, Insert and F1–F12.
Press Esc to cancel recording and click Delete to remove a binding; Esc can itself
be bound with modifiers. Duplicate bindings report a conflict. Bound keys take priority
over terminal input; combinations without Control/Command leave ordinary text fields editable.
Restore defaults in the capture dialog resets only that shortcut; the page header resets
all shortcuts. Resetting one shortcut reports a conflict if its default is already in use.
Command+1 to Command+9 on macOS, and Control+1 to Control+9 on Windows and Linux,
jump straight to the first through ninth tab, whether or not Settings shows numbers
on the tabs. On Windows and Linux, when no tab sits at that position the key stays
with the terminal, where Control plus a digit can be a control code; if a terminal
program needs Control plus a digit, rebind the number keys to Alt or Control+Shift,
or delete the binding.

Clearing the screen also drops the scrollback above it, but the line the cursor
is on stays, so a command being typed is not lost.

Inside a remote-desktop tab Motty's shortcuts are suspended and keys go to the
remote. **Ctrl+Alt+G** releases the keyboard.

`Alt+Shift+T` inserts a copy after the current terminal, inheriting its connection, working directory, and custom name. Automatic names are generated anew. Each workspace supports up to 12 terminals. Duplication balances an unchanged automatic grid, with the final row sharing the full width. In a custom layout, it splits only the source pane and preserves the other dividers. A maximized terminal stays maximized; restoring shows all panes. Toggling maximization without duplicating preserves the original layout.

While maximized, drag the bottom terminal tabs to reorder them. Dropping saves the order, which also applies to the restored tiled view without changing split proportions and survives restarting the app. Drag near either edge to scroll the tab strip, or press Esc to cancel.
