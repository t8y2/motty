## 备份

把状态导出为一个加密的 `.mottybak` 文件。

## 同步

记录级同步支持：

- WebDAV
- 兼容 S3 的存储
- GitHub Gist

记录带有混合逻辑时钟，删除会保留为 90 天的墓碑，因此多台电脑可以收敛到一致，而不会
互相覆盖。

### 坚果云等 WebDAV 服务

上传时 Motty 会创建备份文件上面的各级文件夹，但有些服务只允许自家客户端创建顶层文件夹，
坚果云就是这样：请先在它的网页或客户端里建一个同步文件夹，再把“文件”填成
`该文件夹/backup.mottybak`。密码要用坚果云账户安全设置里生成的“第三方应用密码”，不是登录密码。

## 只留在本机的内容

标签页、窗口布局、快捷键、字体、密钥路径和云凭据永远不会同步。
