## 服务商

在 **设置 > AI 助手** 里添加服务商。支持 OpenAI 兼容端点和 Anthropic。服务商的密钥保存在
保险库里，不会写进设置文件。

### 本机 CLI 服务商

选择 **Claude Code CLI**、**Codex CLI** 或 **OpenCode CLI**，即可接入本机已安装的
命令行助手。可执行文件路径留空时自动查找命令，也可填写单个可执行文件路径（支持空格，
不支持 shell 命令或额外参数）。路径只保存在本机，不随配置同步；服务商名称、类型和模型
选择仍按现有机制同步。

打开表单或切换 CLI 类型时，路径框会显示自动找到的实际路径；未找到时会明确提示。
不修改自动回显的路径直接保存，仍保持自动查找模式；手工修改后才保存为指定路径。
路径查找不运行 CLI，也不会发起登录。

Motty 中不需要填写 Endpoint 或 API Key，认证和服务商配置仍由 CLI 自己管理。
选择「CLI 默认模型」沿用 CLI 的默认设置，也可以手动添加模型 ID。默认模型条目和成功的
版本探测，都不代表已经登录或获得了模型访问权限。

如果 CLI 已配置可用的第三方平台、API Key 或网关，则不需要再登录官方账号。认证状态
仅作提示，即使报告「未登录」也不拦截发送。Motty 沿用 CLI 的用户级路由和继承的环境
变量，不替换为官方 Endpoint，也不把这些凭据搬入 Motty 的密钥库。

### 在 Motty 中发起登录

选中的本机服务商提供「检查状态」和「去登录」。助手明确报告需要登录时，也会提供指向该
服务商的登录入口。只有点击后才开始授权；打开设置、刷新模型不会自动弹出浏览器或登录。

登录使用独立的**敏感本机终端**，绝不会在 SSH 远端执行：

| 服务商 | 官方命令 | 授权方式 |
| --- | --- | --- |
| Claude Code | `claude auth login` | 官方浏览器授权，必要时在 CLI 中输入授权代码。 |
| Codex | `codex login` | 官方浏览器授权，也可主动选择「设备码登录」。 |
| OpenCode | `opencode auth login` | 先选择服务商，再使用其支持的浏览器、密钥等方式。 |

完成 CLI 提示并关闭登录终端后，手动重试问题。CLI 能可靠报告状态时会重新检查认证；
OpenCode、自定义网关或环境变量密钥模式可能仍显示「未知」，这不会阻止正常发起请求。
网络故障、模型权限错误和任意 401/403，不会一概被判为必须登录官方账号。

登录终端的输入输出不会进入 AI 上下文、会话历史、录制或同步。Motty 不读取、复制或管理
CLI 的凭据文件；官方 CLI 可以在用户授权时保存凭据。取消、Escape、15 分钟超时、删除
服务商或关闭窗口会停止本次登录进程，不会执行退出登录，也不会关闭用户浏览器。登录后
不会自动重发 AI 请求或恢复终端操作。

### CLI 安全与兼容性

每次 AI 请求使用私有工作目录，以及仅对当前窗口和模式有效的短期认证 MCP 入口，不会
打开外部 MCP 开关。CLI 自带的 shell、文件、浏览器和子代理执行通道被禁用，终端和
SFTP 操作仍经过 Motty 的风险审批门。无法提供所需隔离时会明确报错，不会降级绕过审批。
CLI 可执行文件本身属于受信任的软件，Motty 不承诺把任意恶意程序隔离成安全程序。

本机 CLI 的每次有效 Motty 工具调用消耗一个已配置步骤；HTTP 服务商仍按请求工具的模型
轮次计数。每次请求最长 30 分钟，单次工具和审批保留现有限制。Motty 不自动安装、升级或
登录本机 CLI。

共享 CLI 运行时读取当前版本，并统一检查适配器声明的参数和隔离能力，不使用版本号白名单。
缺少必要参数、隔离设置未生效、检查命令执行失败或结果无法解析时，提示会说明 CLI 名称、
检测到的版本和具体失败的检查项。无论版本号如何，原生工具隔离仍然是必要条件。
Codex 仍会暴露仅用于 MCP 协议的资源辅助函数，但 Motty 私有入口不发布资源，并拒绝资源
枚举和读取；这些函数不能读取本机文件，也不能访问其他 MCP 服务。

## 模式

**Ask** 以当前可见的终端为上下文回答问题。

**Agent** 还可以在该终端里执行命令，并通过 SFTP 读取和修改文件。

在 Ask 模式下，如果请求需要某个工具，助手可以请求切换到 Agent。你批准后，请求会在
Agent 模式下重试，并记住这个选择；你拒绝时，助手会不借助该工具直接回答。

### 附件与上传到 SSH 主机

回形针把文本、Office 文档提取的文字或图片交给模型阅读，不用于传输构建成品。助手设置可选择单文件文本上限 1、4（默认）或 8 MiB；消息历史和模型上下文仍有各自限制，模型可能拒绝过长内容。

要让代理传送本机成品，请切换至 Agent 模式，点击回形针旁的上传按钮，选择普通文件并说明远端完整路径。模型只收到文件名、大小和本次请求有效的文件标识，不会收到文件内容或本机绝对路径，也不能指定其他本机文件。实际文件通过选中连接的 SFTP/SCP 上传，不受阅读附件大小设置限制。每次上传都会显示文件名、目标主机及远端路径供你确认，默认不覆盖已有文件；停止请求会取消上传。只有传输完成才会报告成功。

## 风险与审批

每条命令在执行前都会先分级：

| 等级 | 含义 |
| --- | --- |
| Low | 只读检查，没有副作用。 |
| Medium | 修改文件或配置，影响范围有限。 |
| High | 删除数据、修改权限或特权、停止服务、执行未见过的代码，或其他难以撤销的操作。 |
| Critical | 可能毁掉机器、数据，或者通往该机器的远程访问。 |

低风险的操作直接执行，其余的都会先请你批准。

<Callout type="warn">
  审批门是一种安全控制，不是沙箱。不要把 Agent 指向一台敲错命令就无法接受的主机。
</Callout>

## 你在终端里看到什么

助手执行的命令会显示为命令本身，并在终端左边距带一个强调色标记。Motty 会把自己的捕获
包装和标记从屏幕以及 Motty 自己的命令历史里隐藏起来。远端 shell 自己的历史不在 Motty
的控制范围内。

## 机密

终端文本在送到模型之前会先脱敏，默认开启。
